# 第三十二期底稿：把直播和选集放进开视

用户P40要求直播和影视仓资源内嵌，参考TVBox。本期实际新增原生目录/频道、搜索、选集、播放器、来源导入与有限检测；本地v15双版测试包已生成。

文案建议：“之前的入口主要打开已安装应用。这次把直播频道、影视站点和选集做到开视里面，NAS也保留。先支持M3U和TVBox的普通JSON直链站点。带爬虫和解析器的配置，导入时会说明哪些还不能用。测试包已经做好，接下来在小米电视上验收播放。”

素材安排：

1. v14与v15首页菜单的浏览器截图，标浏览器，不把它们说成原生播放器。
2. 来源样例与导入结构，所有域名使用占位，不录真实token或家庭地址。
3. 本机HTTP接口测试、36项Java断言与实际APK包信息。
4. 预留真机镜头：来源确认 → 分类 → 选集 → 播放 → 唤醒小爱 → 手动恢复。此镜头尚未拍摄，不能提前合成成验收视频。

记录失败与修正：连接器传输失败，旧仓库/路径404和API限额；最终读到takagen99/Box源码。代码复核发现NAS密文记录上限不足以承载512KB媒体配置，改为独立Cipher与限制，没有放大NAS基础限制。复核后将分类请求改为根API，与查阅源码一致；补充请求测试。没有复制上游AGPL实现或声称完整TVBox扩展兼容。

本轮仅底稿与可复现测试，没有新增视频、小红书上传或原生UI截图。[功能与边界](../docs/EMBEDDED-CINEMA.md)。

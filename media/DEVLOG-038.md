# 第三十八期 · 电视上也该一眼认出常用应用

需求P49。12项常用应用换成原厂图片，应用名放在下方。电视里已安装的应用优先显示自己的图标；断网可显示随包品牌素材，读取失败显示统一应用图形。

画面：旧文字占位截图作历史对照 → 当前标准版折叠组展开 → 爸妈版小快捷入口 → 添加应用页上下翻动 → 原始来源和摘要清单。使用[标准版](../docs/images/s52-home-standard-expanded.png)、[爸妈版](../docs/images/s52-home-parents.png)与[选择页](../docs/images/s52-logos-standard-presets-top.png)，不制作电视实拍的假效果。

旁白：“不用再读一排字猜是哪一个应用。这次把常用应用的图标换成了原厂素材。电视里装了哪个，就优先显示哪个的图标。父母常用的几个应用也能直接认出来。”

边界：真实HTML/CSS浏览器画面，安装与NAS状态是合成示例。品牌素材不属于开视商标，不表示合作。当前源码尚未打包或发布；[素材记录](../design-assets/app-logos/README.md)、[提示词P49](../docs/process/PROMPTS-001.md)、[阶段日志](../docs/process/JOURNAL.md)保留整个过程。

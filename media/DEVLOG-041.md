# 第四十一期 · 给安装包减一点重量

用户原话：“下一阶段，能否适度减少一些安装包的大小，目前稍微有点重了”。

已有安装包约82 MiB。拆开后发现里面放了四种CPU架构；普通小米电视下载包先保留ARM32、ARM64，开发模拟器的x86单独按需打包。按旧包实际文件测算，可少约28.6 MiB，估算约53 MiB，缩小约35%。

字幕必须写“旧包分析估算；新版未打包”，不能做成“53 MB新版本已发布”。4K壁纸与Python影视插件继续保留，NAS、直播和影视代码未删减。本轮仅修改本地配置和验包工具，没有上传。

分镜：原APK文件大小 → 原生库和Python架构重复部分 → ARM32/64打包范围 → 估算前后对照 → 下次实际打包与真机检查清单。图表数据只取下方报告，MB与MiB不要混用。

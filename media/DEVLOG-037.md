# 第三十七期 · 让自己的 Agent 给电视做一份资源包

需求：P48。阶段：v18源码开发版；本期没有新APK或公开发行。

## 画面

1. 标准版首页，遥控焦点从看电视依次到看电视剧、看电影、看综艺；停在综艺。
2. 爸妈版四个观看入口与下方较小的常用应用。[标准版](../docs/images/s51-home-standard-ready.png) · [爸妈版](../docs/images/s51-home-parents.png)。
3. 展示混合资源示例：同一文件中的直播、电影、剧集、综艺和点播站点。示例域名是占位地址，不放真实来源或私人令牌。
4. 终端执行 `npm run resources -- validate examples/resource-packs/family.kaishi.json`，显示包ID、修订号、数量和SHA-256。
5. 使用指南展示“制作 → 校验 → 发布原始JSON → 核对发布字节 → 电视短期授权 → Agent提交 → 查询保存回执”的流程。

## 可用旁白

“家里的电视，应该也能有自己的片单。这次我们把综艺单独放到了首页，也做了一种开视自己的资源文件。你可以自己写，也可以让自己的Agent整理：直播、电影、电视剧、综艺，都放在同一个文件里。更新时保留编号，收藏和观看进度也能接着用。”

“Agent提交文件之后，电视还要核对内容和摘要，再保存并回传结果。送达不等于导入完成。这次把文件规范、示例和制作工具一起放进源码，方便别人继续开发。”

## 素材边界

首页图为真实HTML/CSS在Chromium中的截图，应用安装状态和NAS摘要为合成数据；没有电视实拍。授权界面是本机临时家庭服务，MCP交接的保存回执来自合成电视端。生产Java解析器、文件下载摘要校验和两版Android API编译各有记录；没有执行v18 APK或WorkBuddy客户端，不展示虚构的原生导入成功视频。

# 第三十九期 · 把电视上的问题一项项改掉

P50/P51真机反馈：时间被裁、消息第一列贴边、按钮没有间距、回原桌面不正常。用户提供的是电视实测，开发机截图和模拟器验证分别记录，不能互相替代。

分镜：用户报告的问题摘要（隐去真实地址）→ 当前首页与消息页对照 → 原生菜单和来源弹窗（仅在实际验收取得画面后使用）→ 单色新标识与被否定的玻璃稿 → 版本、签名与待验收清单。新图标来自内置生图工具，保留原提示词与原图。

旁白：“这次先改电视上真正遇到的问题。时钟、消息和按钮要在屏幕里站稳，回原桌面也不能靠重启。图标也重新做减法，留下一个打开的视窗。”

事故记录：主机重启丢失临时运行环境和旧debug签名，原安装包保留。补充持久签名备份与校验。没有完成原生验证和公开发行前，不制作‘全部修复、已发布’的字幕。最终安装路径与发行结果待实证补齐。

迁移选择：用户确认新旧版并存。拍摄时展示系统应用信息中的新旧包名和versionCode，不拍真实NAS密码。新版重新配对、配置NAS；旧数据留在原应用。专用发行证书使用持久私有目录和独立副本，素材只展示公开证书摘要，绝不录制私钥、密码文件或完整凭证。

本轮软件验证补充：两版共四个观看入口，原厂应用图标与简洁开口视窗Logo，来源和NAS改为弹窗；家庭HTTP需明确开启并使用私网IP。因主机无KVM，模拟器启动与原桌面回归结果单独记录，不用浏览器画面冒充电视实拍。

实际收尾：两版release构建及签名核对通过，89项测试通过、3项Samba相关环境跳过。模拟器未进入可安装状态，没有取得新一轮原生UI或原桌面前台回执；相关分镜仍待维护者真机实拍，不制作全部硬件验收通过的字幕。

首次使用验装捕获了家庭屏依赖文件404；这是Node测试无法代替浏览器访问的一个例子。补静态白名单并增加真实HTTP导入链检查后，重新验装再发布。素材应保留这一失败与修正过程。

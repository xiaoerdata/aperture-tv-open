# 大屏背景清晰度探索

用户要求默认背景适合大电视。旧图1672×941，4K铺满会放大约2.3倍。

内置imagegen两次尝试：第一张按旧图编辑，第二张全新生成；都要求3840×2160，但实际输出仍为1672×941，没有标作4K，也没有调用收费API或用插值放大冒充原图。两张尝试及原图均留在此目录，不进入APK资源。

最终使用`public/launcher/carezza-4k.jpg`。它是Commons提供的3840×2160衍生图，原摄影5760×3240，Cem Sagisman，CC0。来源、许可和SHA-256见THIRD_PARTY_NOTICES及docs/verification/background-4k.json。下载后未改动像素。应用只叠加独立的CSS暗色层。

是否在真实电视上清楚、黑位是否合适，仍需看实机；像素与浏览器解码检查不能代替电视观感。

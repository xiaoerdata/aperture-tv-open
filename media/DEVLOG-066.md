# 第 66 集：为什么测试通过，电视还是坏的

这是编辑稿，事实以 S90 与原始回执为准，不把模拟器当真机。

1. 开场展示用户报告：同一台小米电视，v33 默认密度下仍然溢出，时钟停在横杠。字幕：上一轮没有修好。
2. 对照三个入口：家庭服务网址、file 页面、电视内的 appassets 地址。原测试漏了第三个启动分支。
3. 展示 v33 原包与只改一份屏保脚本的对照；过早的跳转使浏览器里的缩放与按钮绑定没执行。字幕：先等首页就绪，再交接屏保状态。
4. 展示标准首页、四张观看卡片与设置首项。页面上的数字、截图来自浏览器或模拟器时明确标注。
5. 收尾：v34 是带着可复现失败样本和诊断信息交付的新测试版；最终结论要等同一台电视在默认显示设置下复测。

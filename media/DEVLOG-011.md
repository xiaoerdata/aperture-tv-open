# 三个大入口，一排小快捷

对应P23、过程S19。原话保存在docs/process/PROMPTS-001.md，上一阶段的三入口画面继续保留。

20秒分镜：前5秒完整显示三大入口；5–10秒遥控向下进入常用应用小卡；10–15秒强调家人可在设置选择、更换/清空四个位置；最后5秒回到完整首页，字幕「简单，也别把常用的藏起来」。

静态底图：docs/images/parents-shortcuts-1920.png（1080p）与parents-shortcuts-1280.png（720p）；复现`npm run qa:launcher`。图中的视频应用、音乐、健身、戏曲为布局示例名称，没有冒称电视已安装这些应用。源码中原生固定slot与选择逻辑已实现，浏览器截图不能证明Android实际打开应用。新APK和小米电视验收仍待完成。

可用口播：爸妈版不是只能做三件事。看电视、看剧、看电影留成三个大按钮；常用应用放在下面，稍小一点，也能直接打开。顺序由家人定，固定下来，不跟着使用次数乱跑。

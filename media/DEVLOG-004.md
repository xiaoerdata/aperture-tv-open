# 开发记录04 · 电视不能访问电脑里的127.0.0.1

对应S12。主线：安装包有了，连接家庭服务还不能靠用户猜地址。

| 镜头 | 实际材料 | 字幕 |
| --- | --- | --- |
| 问题 | 输入框中示例地址127.0.0.1，使用合成画面 | 这个地址指的是每台设备自己，电视不会因此找到电脑。 |
| 选择 | start:lan终端的网卡列表；录屏使用示例或遮蔽真实地址 | 选与电视互通的家庭网卡。VPN、容器地址先别急着选。 |
| 连接 | 服务就绪后的二维码和电视地址 | 手机扫码打开工作台，电视填同一个家的地址。二维码不含口令。 |
| 结果 | qa:lan生成的lan-lite-1280.png与lan-guide-phone.png | 当前机器的真实网卡访问、首次配对和留言同步通过；这是浏览器验证。 |
| 边界 | 真机验收清单 | 还要在小米电视上安装、用遥控器试、持续运行。正式连接要配可信HTTPS。 |

不把同机通过私有网卡访问剪成已经在家庭Wi-Fi或旧电视运行；终端只录不含凭证的片段。私有原始QA报告不直接发布。可复现命令：`node --test tests/lan-start.test.mjs`、`npm run qa:lan`。

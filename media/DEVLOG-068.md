# 第 68 集：让电视留住家里的照片

编辑稿；截图、二维码与影片信息都注明合成测试。

1. 方向键从家庭第三屏向上回应用，再向下走到相册第四屏，先展示这次修复的完整往返。
2. 电视开启二维码，手机选择照片，直传到电视；重开相册仍在，手机原图不动。二维码与地址用演示能力码，真实上传窗口不录入公开素材。
3. 同组照片切换柔和叠化、慢慢推近和双幅画廊，展示暂停、继续与相册屏保；所有循环均可被遥控器退出。
4. 收藏从文字按钮页变成海报与信息概览，左侧切换、右侧直接继续播放。
5. 直播侧栏左右切组，确定才换台。注明模拟器机制验证与小米真机验收的区别。

6. 设置开启“桌面守护”，展示等待授权与已连接两个真实状态；主动退出后原桌面不被拉回。录屏前遮住设备序列号。说明借鉴CleanYourTV/Aerial的机制、独立实现；固件广告与桌面广告分别说明，不演成万能去广告。

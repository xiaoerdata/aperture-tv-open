# v39 修订版：加载恢复与相册兼容

标准版 `0.2.0-alpha.36-r1` / versionCode 39，仅适配小米电视 Android 8+。这是公开预发布测试版，尚未完成全部云端回归或小米真机验收。爸妈版暂停更新。

## 本版变化

- 首页加载失败可进入原生恢复界面；切后台或小爱等窗口导致失焦时暂停前台期限，避免把不可见时间算作加载失败。设置和应用工具页提供本机诊断。
- WebView 低于 89、版本未知或相册网页加载失败时使用原生相册，支持本机照片浏览、全屏逐张播放、暂停与返回。原生模式暂缺二维码、网页模板与照片管理；手机上传需手动输入临时地址。
- 上传统一先显示原生确认，默认取消。确认只对当前界面和一次开启有效；退出、结束活动、切后台或界面更换立即撤销，异步晚到结果不得继续显示地址或刷新旧界面，回前台不自动恢复。
- 本地诊断记录固定阶段与计时，不记录照片、上传地址、令牌或网页正文。

保留 v36 的第四屏相册、双向翻屏、收藏概览、直播左右切组及可选桌面守护。默认不申请桌面接管，不修改 density 或电视分辨率，不停用小爱、米家、账号或原桌面。固件阶段开机广告不在普通 APK 的保证范围内。

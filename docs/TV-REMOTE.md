# 电视遥控布局

当前页面与按键为S50，见[首页与遥控翻屏](HOME-PAGES.md)。安装包版本与发布状态以项目README和Release记录为准；旧验证材料按阶段保留。

## 页面与按键

- 标准首页：时间、日期、风景，三张“看电视、看电视剧、看电影”小卡片；默认焦点在看电视。左右选观看入口，向下到常用应用组，确定或向下展开；组内左右选应用，上键或返回收起。
- 逐屏向下：展开应用向下到翻屏按钮，再向下进入“片库与应用”；第二屏的应用行继续向下到“家庭”。返回逐屏上返并保留可见焦点，离屏时收起的应用组恢复到组入口。设置也可用菜单键打开。
- 爸妈首页：看电视、看电视剧、看电影；下方四个常用应用和所有应用。主入口向下进入对应快捷区域，向上可到设置。
- 分区：保留相册、数据、消息、工具；进入后显示内容，不重复挤入八入口。返回恢复原入口焦点。
- 设置：单列操作列表，上下移动，首项向上到返回；返回关闭后恢复原焦点。添加应用和壁纸选择是三列网格，竖屏预览为两列；应用选择页保留生成燕子插图。
- 片库：标准四列、爸妈三列；上下同列，右边界不跳到下一行。播放器保留大按钮播放/暂停、后退与前进；移除浏览器小型原生播放控件。

当前以1920×1080等比画布适配电视；首屏观看卡236×110设计像素，标签30px；一般操作至少72设计像素，页码/轮播辅助按钮64设计像素。爸妈核心标签46px，主卡236px高，常用应用108px高。实际CSS像素会随画布缩放；普通入口标签至少24设计像素。原生简洁首页/NAS按钮改为至少72dp、24sp，爸妈核心按钮采用28sp。CSS像素、Android dp和电视物理像素不同；这些数值不等于已经完成3米阅读或中老年实机验收。

## 背景

`public/launcher/carezza-4k.jpg`实际3840×2160，2,471,360字节。来源摄影5760×3240；下载Commons的4K衍生文件后没有改像素。作者Cem Sagisman、CC0，详细来源和SHA-256见THIRD_PARTY_NOTICES。背景内置到APK，通过精确HTTPS白名单读取，不访问外部图床；CSS独立叠加暗色层，仅下半区域以渐变遮罩模糊。另新增三张世界风景，可在设置→壁纸切换，两版独立保存；来源与尺寸见[素材清单](verification/s48-wallpapers.json)。

早期未采用的背景尝试保留在media/research/background-4k。S49另内置imagegen生成的1672×941“暮色湖面”，它是第五个可选背景，明确不标为原生4K；原图与生成过程见design-assets/s49/README.md。

## 验证与边界

`scripts/browser-tv-controls-qa.mjs`在720p/1080p/4K运行生产页面和原生按键名称契约，验证行列边界、设置可达、菜单/分区返回焦点、可见控件尺寸，以及真实3840×2160背景解码。片库的八个文件是明确不可播放的布局夹具，不用于证明解码。

既有launcher回归另覆盖家庭内容、撤销和轮播；家庭代理专项检查照片/分页/过期/撤销；影院专项实际解码VP9 WebM和HLS并验证暂停、拖动、返回及关闭。两版Android API编译通过。这些证据分期保存，不合并成全套真机通过。

主报告：verification/tv-controls.json、s31-launcher.json、s31-cinema.json、s31-native-household.json、s31-native-api.json、background-4k.json。实际截图在images/remote-final-*与s31-standard/parents-*。真实遥控、小米固件、WebView性能、原生控件渲染、NAS硬件和两小时稳定性仍待验收。

S50定向证据：[首屏、21组电视布局与三屏回焦](verification/s50-home-entries.json)、[两版遥控](verification/s50-tv-controls.json)、[摘要与预设](verification/s50-home-personal.json)、[壁纸](verification/s50-wallpaper-browser.json)。截图来自桌面Chromium，应用/NAS状态为合成数据，不代表小米实机通过。S48/S49报告保留，不覆盖。


## S53 · 返回原生桌面

原桌面候选排除开视标准版、爸妈版及其别名。优先使用已保存且仍有效的入口，或系统当前原桌面；部分小米固件隐藏HOME条目时，只接受实际解析得到且为系统应用的小米桌面入口，不猜Activity类名。选择后立即启动，不先重建开视首页。启动成功才结束开视当前任务；失败可重新选桌面或进入系统桌面设置，不自动重启电视。

这是一次返回，不擅自更改用户默认HOME。若希望遥控器Home键以后也回原系统，请在原系统默认桌面设置恢复原桌面，或在开视默认桌面设置移除本版候选。部分固件不提供系统桌面设置Activity时回退到系统设置。实际小米前台切换仍须现场复验。

# 小米电视应用安装与卸载

本项目仅适配小米电视。源码v13提供实际APK选择、私有缓存与原生安装器交接；v12只有安装指引与入口配置，不能拿v12验证新安装功能。

## 人在电视上安装

设置 → 安装应用 → 选择本机APK，或从NAS选择APK。原生简洁首页、玻璃首页和爸妈版家人设置使用同一安装控制器。

本机路线使用系统OPEN_DOCUMENT/GET_CONTENT文件选择器，只接受用户选中的content URI，不申请整个存储权限。部分电视固件没有选择器；可从已保存NAS连接的“全部”列表选择“安装包”，或用原系统文件管理。NAS读取复用SMB2/3和HTTPS WebDAV，只读原文件，不上传APK或NAS密码到家庭服务。

独立APK复制到电视自己的缓存，最多200MB；未知长度也按实际字节限制，取消、断流、长度不符均删除不完整副本。解析包名、版本并计算SHA-256后，用户复核，再检查“允许此来源安装”权限。原系统授权返回后再次复核，不静默继续。

仅向公开、已启用且导出的系统安装器交接单个缓存文件的临时只读content URI。非导出的InstallFileProvider只允许读取确切UUID文件，不列出目录或写入；两版authority独立。系统回调后清理当前缓存，未完成的旧副本下次使用时按24小时清理。APKS、XAPK及拆分包暂不支持。

系统报告完成后核对安装版本，提供“添加常用应用”。看不到可启动入口的后台组件或手机专用应用不一定能显示在电视应用列表。第三方账号、数据、直播或影视仓配置仍由原应用管理。

## WorkBuddy安装与卸载

[WorkBuddy官方步骤](WORKBUDDY.md#安装卸载电视应用源码v13)使用同一安装器及系统卸载确认。手机管理员分别授予apps.install与apps.uninstall，默认不勾选，已有令牌不扩大。

电视主动开启一次、10分钟的操作窗口。安装范围是本次共享的NAS连接ID和名称；WorkBuddy提供相对APK路径、包名和确定的SHA-256，电视复制后必须匹配。禁止Agent更新小米系统组件或两版开视本身；这类维护请使用人工官方升级路线。卸载只允许本次列出的非系统、可启动应用，且实际执行前再次检查。卸载不删除NAS的APK原文件，可能清除该应用自己的数据。

发起安装、卸载前再次校验Agent与电视授权。请求、读取缓存、等待系统确认和最终结果分别记录；每次逻辑提交使用固定幂等键和窗口revision。状态不明、过期或服务重启后不能自动重发。系统安装器已打开后的撤销无法撤回原系统已接受的操作，此时不明结果标为unknown。真实电视回执由原生代码核对；服务器的reported_by_tv是设备报告，不是独立硬件证明。

## 开视自身升级与故障

- 开视APK按具体机型支持的U盘或已授权单台ADB方式安装，不Root或刷固件。默认不更换原桌面。
- 同包名、同签名、版本号不回退时覆盖升级。不要先卸载；家庭连接与NAS配置可能被清除。私有debug签名不能冒称正式发行签名，未来签名迁移须在正式发布前确认。
- 签名不一致或安装失败时，保留错误文字并核对文件、Android版本和CPU架构。禁止为了修复安装自动卸载旧应用、停用系统保护或删除数据。
- 需要卸载开视本身时走原系统应用管理。当前Agent管理不提供自卸载；服务端的电视授权需另行撤销。

源码/协议/合成回执测试、模拟器运行与小米真机验收分开。WorkBuddy客户端、小米电视上的文件选择器/来源授权/原生安装确认由项目维护者现场测试；未测试的机型不标为兼容。

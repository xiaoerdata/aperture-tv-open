# v17小米真机反馈处理 · S53

用户提供MiTV-MTSU0、Android14、1920×1080 override的v17测试PDF，并补充无法返回原生桌面。原报告为用户的硬件证据；本轮开发验证单独记录，不把模拟器或Chromium结果称为已在该电视复验。原PDF和实际家庭地址不随公开源码发布。

旧v17在当前桌面Chromium中没有重现报告的裁切，不能把浏览器通过当成根因确认。修正同时覆盖DOM祖先滚动与Android WebView自身滚动；不只增加边距。Android旧提供者的强制测试页与正式玻璃首页门槛分别记录，不降低产品WebView89门槛。

当前两版源码仍为v18 / alpha.15；按P55使用新包名、新发行证书与v17并存；旧数据和旧发行不变，新版重新配对与配置NAS。发行证据、截图和已知限制在本阶段验证与发布记录中补齐。

本轮两版非debug构建、签名与实际APK资源核对通过；Node测试89通过、3项因Samba环境缺失跳过、0失败。原生UI测试驱动已构建，但模拟器无KVM且ADB未就绪，未安装产品、未验证原桌面前台。详见[软件记录](verification/s53-software-acceptance.json)与[环境失败记录](verification/s53-native-environment.json)。本版供维护者真机复测，不标为已完成全部设备验收。

公开源码首次安装检查另发现家庭屏模块依赖404：已补明确静态白名单与12项HTTP服务回归，未开放其他shared模块。APK输入摘要不受该服务器修正影响。最终发行使用修正后的源码快照。

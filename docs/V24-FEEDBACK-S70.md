# v24回归修复 · v25候选

仅适配小米电视，Android 8+。原报告测试的是v24标准版、MiTV_MTSU0、1080p；它不是v25或爸妈版的真机验收。本轮开发验证分别记录浏览器、主机JVM与Android模拟器。

## 交互取舍

观看者用方向键完成选择，进入分区先见直播或影片信息；侧栏只承担来源、分类、筛选与频道导航，影片在右侧浏览。保留深色玻璃风格，以较大的文字、两行片名、清楚的分组与焦点建立层次。沿用本项目TV-VIEWPORT与Apple TV应用浏览的图标/标签组织思路，不复制其素材。

- 点播进入仍先显示首部影片详情；“片单”、分类与搜索进入右侧海报网格，不再跳到右侧分类九宫格。默认五列，折叠侧栏时六列。
- 分类留在左栏，来源和分类可各自展开；片名不再混入导航树。电影、电视剧、综艺复用同一套状态。
- “加载更多”累加当前来源返回的页，按影片ID去重，最多400部；只显示已加载数量，移除上游页数与本地切片页数相互矛盾的显示。
- 年份、地区明确只筛选**已加载内容**。本轮不声称支持所有TVBox插件的服务端筛选，也不虚构源站总数、评分排序或热度。搜索在当前来源进行，已加载结果按标题完全匹配、前缀、包含顺序稳定排序。
- 超时保留侧栏，提供中文错误、重试、切换来源和来源设置。加载态保留相同页面骨架与读取提示。
- 输入法提供搜索/完成提交；输入框收到右/下方向键时先收起IME再聚焦搜索。系统输入法若先消费方向键，仍可用输入法搜索动作或返回键收起键盘；系统小爱语音键继续交还原系统。
- 直播直接全屏。频道选择是覆盖在左侧的可滚动浮层，不挤压视频；“更多”提供收藏、节目单、音轨、直播来源等；点播另有变速和选集。画质由来源实际提供的线路决定，不伪造分辨率切换。
- 频道确认键从按下到松开由同一浮层持有；长按期间暂停浮层自动收起。重绘时忽略临时焦点事件，避免选中频道被首行重置；上一/下一频道也同步更新频道引用。
- 首页四个观看入口380×132设计像素；应用图标96像素，名称可两行。已知品牌使用预设短名称，图标保留原厂素材。v25首次进入恢复展开一次，之后尊重用户自己折叠的选择。“所有应用”固定在应用行末，左右方向键不会跳到数据组件。
- 全应用页固定五列、纵向滚动，少量应用不会拉伸为整行；读取PackageManager真实图标；最近使用最多5项，长按提供设为常用、系统卸载确认和应用信息。

## 需要区分的报告推断

1. 源码在v24已有XMLTV/gzip读取与频道匹配，不是“没有接数据源”。无节目数据不能证明解析器未实现。本轮新增独立节目单地址设置及空数据说明，不打包公共EPG源；用户可以使用自己有权限的地址。覆盖设置加密保存，可清除，不变更资源包修订号。配置HTTP仍遵循显式允许策略。
2. 原生`CinemaVault.importConfig`保存整个新配置，不是合并旧站点。本轮资源包验证需检查导入后的实际站点与频道数；原报告资源包未提供给开发环境，无法确定其“7个站点”的来源。
3. “更多”和频道抽屉在v24源码是不同组件，报告描述的重复可能涉及焦点/事件流；本轮按真实操作路径验证，不把推断当作复现根因。

## 验证入口与限制

- 浏览器：`node scripts/browser-s70-home-qa.mjs`；合成应用槽位与NAS摘要，不能代表本机应用已启动。
- 原生：准备`.android-local`工具目录和名为`kaishi-s53-tv28`的API28 x86 AVD；在测试虚拟环境安装OpenCV后运行`python3 scripts/fetch-public-media.py`准备本机样流（外部URL可能变化），构建x86 debug，再运行`python3 scripts/run-s70-native.py`；仅操作自己启动的Android TV API28只读模拟器，合成目录与XMLTV，本地Mux HLS测试片段及Blender测试短片/配图。首次启动需软件CPU及swangle、关闭Vulkan；测试结束关闭自己的进程。不会扫描用户网络或控制真实电视。
- 领域：`tests/cinema-browse.test.mjs`、既有台标地址、EPG、资源包与播放会话测试。工具目录通过环境变量设置，见ANDROID-LOCAL。
- 下载版保持ARM32/64及既有发行签名，和模拟器包分别构建、核对源码/编译输入；测试驱动不进入产品。

领域分批验证见[10组记录](verification/s70-domain-summary.json)，首页浏览器验证见[任务记录](verification/s70-home-browser.json)。最终原生结果与发行绑定见[验收清单](ACCEPTANCE-S70.md)；过程日志保留未通过的候选与原因。小米真机的换台焦点、具体输入法、系统返回、小爱、米家、NAS与WorkBuddy仍需维护者复验；不把v24报告中的通过项自动变成v25通过项。

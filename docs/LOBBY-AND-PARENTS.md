# 客厅一级入口与爸妈版

当前本地界面见[S48首页留白与翻屏](HOME-PAGES.md)：标准三屏、爸妈卡片缩小、两版独立透明与壁纸设置；尚未更新公开alpha.13 APK。下文保留早期P14/P15及后续各阶段记录，旧安装包不能用于验收S48。

面向拿起遥控器就想看电视的家人；首屏主要动作是选择去哪里。标准版保留家庭内容与媒体路径，爸妈版优先减少步骤、增大文字和明确焦点。这里切换的是前台应用与桌面入口，电视固件仍由原系统管理。

## S14–S47历史：八个一级入口

`/home`（网站根地址也进入此页）提供家庭窗景、电视直播、影视仓、家庭相册、今日数据、家庭信息、家庭工具、原生桌面；顶部提供总览、相册、数据、信息与工具分区，轮播可手动切换或显式开启。`/tv`保留原完整窗景，旧内核仍可进入`/tv-lite`。

电视新版外壳启动先读取APK内置的客厅页，家庭服务未配置或离线时仍能打开已安装应用、原桌面和系统设置。家庭内容、直播内容和视频能否播放，分别依赖家庭服务或所选应用自己的网络条件。

1. 进入“电视直播”，首次从电视已安装应用中选择直播应用；以后可以直接打开。也可进入“我的家庭频道”，只看自己添加的M3U/HLS。
2. 进入“影视仓”，选择电视上已有的影视仓或播放器；片源、账号和播放记录继续留在原应用。“我的家庭片库”另行展示电脑/NAS/Jellyfin视频。
3. 进入“原生桌面”，切回已确认的原桌面组件。不会发一个泛化Home Intent再把开窗自己打开；两个开窗版本都不作为原生桌面候选。
4. “入口设置”可更换绑定、家庭服务地址及系统默认桌面。候选只来自系统报告的已安装、已启用、可启动Activity，不接收网页传入的包名或任意Intent。

当前源码新增「玻璃 / 简洁本机首页」；低于WebView89自动使用原生简洁入口，现代内核也可手动选择。渲染进程退出时清理对应网页并回到原生入口，本次不自动重建网页；原生NAS和应用保留。[选择规则、恢复与实机边界](HOME-MODES.md)。该设置与家庭屏轻量模式、系统默认桌面分别管理。

## 爸妈版：三个常用入口

独立安装名“开窗·爸妈版”，包名`org.zhixiaoce.aperture.parents`；标准版为`org.zhixiaoce.aperture`。两版可同时安装，应用绑定、家庭地址与会话各自独立；不会自动复制标准版的授权。

- 首页突出“看电视、看电视剧、看电影”三个大入口，分别进入后台统一配置的直播、剧集、电影；返回保留爸妈版。
- 三主入口下方有更小的四个常用应用位置与「所有应用」，同屏一按打开。家人设置 → 管理常用应用，选择、更换或清空；未添加时显示待家人添加，应用已卸载/停用时提示重新配置。绑定留在本机，不依赖家庭服务在线。
- 默认大字、实底、高对比、粗焦点，不提供首页光线切换和连续背景动效。初始焦点在“看电视”，排列固定，不自动换位。
- 设置在“家人设置”内；家庭工作台的「家庭影院」统一开启、选择片库、设为电视剧/电影、导入M3U。后台自动检测源；没有配置时明确提示家人准备。原桌面切换留在设置中。
- 日常首页不放相册与留言入口；家人设置仍可进入简洁家庭屏。数据连接和媒体配置由家人在手机/电脑管理。
- 开窗内按返回先收起弹层、返回首页；爸妈版首页按返回留在首页，避免误退。外部播放器的返回行为由那个应用决定；Home键回哪个桌面由系统默认项决定。

这是一套已实现的适配规则，尚未完成真实中老年用户测试，不能称为适老认证或全型号兼容。

## 开机、Home与原系统切换

默认HOME候选关闭。在“默认桌面 / Home键设置”中先主动开启本版候选，再由系统和用户选择开窗。支持更换默认HOME的固件，系统进入HOME时会打开客厅入口；MainActivity采用singleTask，重复Home返回同一个入口。

部分小米固件限制默认桌面或有自己的开机流程，此时仍可从原应用列表启动开窗。没有接管开机广播、后台强行拉起、Root、禁用原桌面或修改系统设置。默认桌面设置不存在时回退到系统设置，两个入口都不可用时提示用原遥控器设置键。

从原生桌面回开窗：若开窗是默认桌面，按Home；否则从原系统应用列表启动。恢复原默认桌面也在系统设置完成。“切回原生桌面”只临时启动该组件，不偷偷改变默认项。

## 两版的打包入口

`npm run android:apk -- --edition standard`、`--edition parents`、`--edition both`选择标准版、爸妈版或两版。仍走隔离本地免费工具，不触发托管CI。产物分别在artifacts/android-local与artifacts/android-local-parents，来源清单含edition、包名、签名和校验值；APK内置客厅资源纳入Android输入摘要。

历史私有候选versionCode4已包含上述本机入口、深色主页和爸妈版快捷栏；两版各自与v3包名及签名相同、版本递增，十份内置资源与源码逐字节匹配。v3和v2保留作历史候选，不能用旧包验收新界面。构建证据不替代真实电视安装或实际覆盖升级。下载见private-preview索引。

S14曾生成两版v3并核对四份资源；S20升级为v4，66项Gradle任务成功，十份资源逐字节核对，debug签名保持一致。下载见[私有版本选择](DOWNLOADS.md)。包名不同，可同时安装；两份文件不能仅靠改文件名互相替代。

## 视觉与验证

当前保留拱窗标志，采用深色全景、分区与玻璃导航；爸妈版保持实底大字。之前P14/P15的清亮SVG客厅仍见旧截图与v3安装包，当前变化详见[深色玻璃说明](DARK-GLASS-DESIGN.md)。参考[Android TV导航](https://developer.android.com/training/tv/get-started/navigation)的可预测焦点/短路径，以及既有Apple Materials与Carbon网格研究；不复制品牌、界面截图或商业字体。默认桌面使用[Android系统设置入口](https://developer.android.com/reference/android/provider/Settings#ACTION_HOME_SETTINGS)，保留无处理Activity时的回退。

`npm run qa:launcher`覆盖两版、720p/1080p/4K、手机与760/761边界、遥控按键入口、弹层焦点、家庭屏来回、离线文件加载和文本化标签；`qa:cinema`覆盖家庭频道/片库分流与原播放流程。浏览器和编译不能证明真实Android应用切换、开机行为或实体遥控器已通过。


## 源码v6：把NAS目录交给三个大入口

家人在NAS中打开电影/剧集目录，选择「将当前目录用于首页入口」并确认。爸妈版看电影/看电视剧直接进入已选目录，未指定时保留家庭服务；看电视继续走已配置频道。NAS相册在家人设置可打开，四个小快捷不变。标准版在影视仓的我的家庭片库明确选择NAS电影、剧集或家庭服务完整片库。

选定目录是本次浏览根；返回不跨到其他共享目录，并恢复上一级页码和焦点。绑定使用固定连接ID，删除前面一个连接不改变当前入口；忘记连接同时移除它的绑定，家人可逐项恢复默认。NAS网络错误不会暗中改用另一台NAS。

本机来源标签返回首页时更新，不重载或抢走遥控焦点。设置按钮在现代WebView也始终保留焦点环，爸妈版主按钮不再用未选中白底冒充选中。浏览器截图为合成标签，原生Intent、Keystore、老电视与NAS仍待实机。v5没有这些绑定功能，包版本请核对私有下载索引。


P28/P29：当前源码标准版八入口改为两行四列；标签缩短为功能名称。爸妈版三大观看入口与五个应用控件保留。设置改为单列大按钮，页内返回恢复焦点。默认背景实际3840×2160，来源许可与测量见[电视遥控布局](TV-REMOTE.md)，下文较早截图按其阶段保留。


## S51 · 下一版综艺入口

v18源码中，标准版首屏和爸妈版均增加“看综艺”。爸妈版改为四个观看入口一行，常用应用保持较小的一行；标准版仍保留风景、摘要和折叠应用，四个观看入口沿原行展开。方向键依次选择电视、电视剧、电影、综艺，向下进入常用应用。新布局见[标准版](images/s51-home-standard-ready.png)与[爸妈版](images/s51-home-parents.png)，[遥控与尺寸检查](verification/s51-home-entries.json)。图片为浏览器画面和合成状态，未更新公开APK。

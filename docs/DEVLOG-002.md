# 开窗开发记录 002：从共享屏到家庭中枢

2026-10-24，开发环境，无应用构建、无外部发布。

本轮把项目定位升级为家庭信息、手机协作、可选影音和个人助手共同使用的中枢。保留原创三窗景，新增生活来源目录与用法、MCP消费框架、选择分享快照、可选本地/Jellyfin/M3U影院、交互介绍指引、WorkBuddy兼容的本机授权编排。

过程中的具体发现：
- “源码公开”不等于宽松开源许可：小米 HA 桥接为自定义非商业许可；mijia-api README与GPL许可说明存在差异，目录单独标记。
- 和风项目的许可文件是小写 license，进一步核实后更新目录为MIT，没有把初次查找失败当成最终结论。
- SDK安装审计发现旧版本公告，固定升级到1.32.1；hls.js固定1.7.3，安装时 npm audit 0项。
- 浏览器流程发现影院复选集合错误，修复后继续真实播放验证。当前 Chromium不含H.264解码器，使用VP9 WebM与VP9 fMP4 HLS验证播放，不把结果扩张到小米硬件。
- 助手工具执行与电视渲染分开回执。SSE只通知revision，数据仍经鉴权读取，断线用原轮询补偿。
- 介绍页的动态家庭示意有场景切换、暂停、离屏/后台停止和系统减少动态；全部为原创CSS图形。

素材叙事：一条“我到家了”是输入，窗口标题和留言是输出，手机上的授权与撤销是控制权。录屏必须标注协议测试、合成家庭资料，不能冒充 WorkBuddy真机应用或小米电视现场拍摄。

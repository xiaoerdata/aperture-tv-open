# 私有APK候选：从CI到真机

用户P13要求免费替代托管CI后，已验证隔离本地定向构建并提供[私有debug候选](DOWNLOADS.md)。本地使用JDK17、Gradle8.9、SDK35生成APK，并核对包名、版本、min/targetSDK、签名和SHA-256。GitHub工作流仅保留为手动可选入口；此前托管运行未开始编译，本地成功不代表远程CI成功。

候选仅供授权的私有仓库协作者测试，不自动发布到Release、不改仓库可见性、不部署服务。本地debug密钥保存在私有运行目录；可选托管流程使用runner的临时debug签名，不同环境的签名可能不同。升级前核对签名，正式发行需要项目专用稳定签名。

## 下载和首次安装

1. 从[私有候选目录](DOWNLOADS.md)下载APK及校验资料，或按[免费本地构建](ANDROID-LOCAL.md)生成。若改用可选托管流程，须确认apk作业实际成功再下载14天有效的artifact。候选资料包含APK、manifest.json、SHA256SUMS、package.txt、signature.txt。
2. 核对manifest的sourceCommit与候选注明的源码提交（PR头部可能另有打包或文档提交）；核对APK的SHA-256与签名摘要。不把只下载成功当作安装成功。
3. 按明确型号的官方侧载流程安装，或在电视授权ADB后，对已经确认的单台设备执行 `adb -s <serial> install -r aperture-tv-debug.apk`。不扫描家庭网络、不批量安装、不改变原桌面。
4. 如果提示签名不一致，先核对当前安装的包确为本项目开发版；需要卸载开发包时会清除本地服务地址和会话，之后重新配对。不要卸载名称相似的其他应用。
5. 仅使用本机应用或手输NAS时，可先跳过家庭服务。需要共享内容、后台片库或助手交接时，再输入真实家庭服务源地址；本机127.0.0.1不能给电视访问。内测debug允许HTTP，私人资料与助手凭证仍应使用可信HTTPS；release候选只允许HTTPS。

## 先验证三个关键动作

- 先用方向键、OK和返回操作本机首页；旧WebView使用原生简洁首页。需要共享时再连接家庭服务，家庭屏另选轻量模式。通过原生传入按键名称的统一入口测试，不仅在电脑上敲键盘。
- 手机/助手加一条合成留言；记录服务版本、电视呈现和回执。尝试刷新、断网重连及撤销。
- 打开原生“应用与系统”菜单、启动已有应用、退出与卸载；确认原电视桌面仍可使用。

继续填写ANDROID.md的型号、系统、WebView、安装证据、观看距离和2小时运行矩阵。CI编译、签名验证和浏览器按键验证都不能替代这张真机记录表。

私有候选URL、提交与验证结果以本次执行记录为准；未有artifact时不提供假下载链接。

## 在浏览器里先检查电视

在目标电视打开 `/diagnostics`，或从家庭屏进入“电视检查”。页面会显示声明的Android/Chromium版本、屏幕区域、完整/轻量建议、服务连通性，以及从相同原生入口收到的按键。摘要仅在当前页面生成，不读取管理口令或家庭板。

这一检查可以帮助选择路线与记录现场环境；浏览器声称的版本和能力检查通过，仍不能替代APK安装、遥控硬件和两小时稳定性测试。

## 片库内直接连接

新版源码的电影/电视剧/直播页在未连接或被撤销时显示「连接这个家」。按下后生成只读连接码，家人通过工作台的「连接与窗景」批准；电视领取会话后留在原列表，不必先跳转家庭窗景。关闭弹窗会中止本页请求并丢弃申请端secret；代码未被领取时仍按服务端五分钟期限失效。过期或失败需主动重试，不自动生成新授权。

配对与后台检测属于家庭服务，安装APK不代替启动服务；更新候选时也应运行对应源码提交的家庭服务。实际包版本、签名和来源以私有下载索引与本包manifest为准。


## v5：NAS 与首页实测（历史步骤）

v5是历史候选，当前版本以私有索引为准。先从影视仓/工具或爸妈版家人设置进入「家里的NAS」，用专用只读账号测试一个小目录，再检查中文文件、照片方向、MP4播放/拖动、按返回、失焦/小爱浮层与NAS休眠后重连。小米只按最新Xiaomi智能存储验收；请记录实际型号与固件，协议未确认前不当成已兼容。v5的NAS配置不需电脑服务，仅支持家人在电视输入；当前候选另有下文的手机/Agent交接。

标准版另测：家庭服务配对后返回首页，照片/数据/信息可分页；撤销这个电视的会话，下一次读取清空共享卡片与详情。爸妈版保持简洁，不显示这些首页摘要。实测报告只记录必要状态，不上传NAS账号、地址、密码、真实家庭照片或会话码。


## v6：给三个观看入口选NAS目录

新版候选已包括目录用途绑定。家人在NAS中打开一个小的电影/剧集目录，确认「用于首页入口」；回爸妈版，检查对应来源名和直接打开。进入子目录、翻页、开影片、返回，记录页码/焦点是否恢复。检查准备播放时被小爱打断后不会自行开始，重新打开只恢复目录。再忘记一个未使用连接，确认已有绑定仍指向原目录；恢复默认后应使用家庭服务。

这些步骤尚未由真实电视执行。两个edition设置独立，不从标准版自动复制给爸妈版；使用同签名更高版本的覆盖条件也不代表实际升级已成功。出现问题保留数据和错误文字，不要直接卸载。

## v7：影片把声音让给小爱

原生NAS播放页新增音频焦点处理。选一段可解码的小MP4，在准备中和播放中分别按语音键/唤醒小爱，检查即使页面没被遮住也会暂停。退出助手后等待，影片仍应暂停；按播放才继续。再测主动暂停、返回目录、播放完毕、断网读取失败和切换影片，检查旧回调不会让新影片停下或自行开始。声音忙时应提示稍后按播放，不能直接出声。

本轮开发测试只运行生产播放意图控制器及API编译，Android AudioManager/MediaPlayer与小米固件仍未实际执行。外部影视/直播应用和网页影院分别测试，不把NAS原生行为推及它们。原生NAS页仍启用隐私截图保护；提交结果只需型号/固件和错误文字，无需上传语音、私有片库或账号。

## v8：不在电视输入NAS账号密码

更新对应家庭服务源码并使用可信HTTPS，电视完成只读配对后进入「家里的NAS → 用手机 / 助手配置NAS」。保持接收页打开，手机扫码、验证管理员、核对校验码，再用小目录专用账号交接。检查电视先测试后保存，手机区分「等待电视」与「电视已报告保存」。从目录返回首页检查新用途；不选用途时应只增加连接。标准/爸妈版分别配置，不复制凭证。

再测返回/切应用取消、10分钟过期、家庭服务重启、错误密码、撤销配置者权限、断网和回执丢失。出现「已保存；回执未送达」先查看电视连接，不重复添加。此通路需要HTTPS；原生手输/读取仍可独立使用。Android Activity/CookieManager/Keystore、实际摄像头扫码和品牌NAS均待真机；JVM/浏览器测试不能代替。全步骤与Agent本地加密助手见[NAS交接](NAS-SETUP.md)。

## v10：大按钮与4K背景

下载索引当前为 v10。标准版八入口两行四列，爸妈版三个观看入口和常用应用；不使用鼠标，分别从初始焦点按左右到边界、上下同列，再走到顶部设置。关闭设置后应回到原入口；从电影/电视剧列表返回也应保留焦点。检查设置、NAS、播放器按钮在正常观看距离是否易读、易选。

默认背景已内置为 3840×2160 JPEG（约 2.47MB），无需联网下载。检查电视实际输出分辨率、近看边缘与文字、冷启动和连续切换，不以浏览器4K截图代替电视观感或流畅度验收。老 WebView 自动简洁首页不使用该玻璃背景。切换玻璃/简洁模式并重开，检查偏好保存、原桌面入口、直播/影视应用和小爱语音键/唤醒。

本次已通过浏览器遥控路径/720p/1080p/4K尺寸、实际APK资源与清单检查，尚未在真实电视执行上述步骤。家庭服务配对和NAS配置继续沿用前文；更新服务至候选源码提交。反馈型号、固件、结果或错误文字即可。

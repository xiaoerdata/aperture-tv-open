# 首页应用与家庭摘要 · S50

标准版首屏保留风景和大时间，提供“看电视、看电视剧、看电影”三张紧凑入口。下方为可折叠的常用应用组，右侧按已授权内容出现摘要。爸妈版仍保留三个观看入口及一行较小的常用应用，不把主要入口藏进折叠组。

## 遥控器

- 首屏默认焦点在“看电视”，左右选择电视、电视剧或电影，按确定直接进入对应内嵌入口。
- 从观看卡按下选中应用组，按确定或下展开；组内按左右选应用，按上或返回收起。收起时内部按钮隐藏且不能聚焦、点击。
- 从展开应用按下到“片库与应用”翻屏按钮，再向下进入第二屏。第二屏应用行再向下到第三屏“家庭”。返回逐屏上返；离屏时收起的应用组恢复到组入口。
- 进入组内“添加应用”选择预设。弹窗按三列移动，返回恢复原焦点。
- 从“看电影”按右可到已配置摘要，支持手动下一条和暂停；打开分区后返回首屏。若内容被撤销导致摘要消失，焦点回到“看电视”。

折叠展开约380ms、依次间隔35ms；收起180ms。打开应用选择页时燕子入场800ms，NAS摘要获焦时插图轻移650ms。都是有限动画。设置可以关闭装饰动画，也遵循系统减少动态效果；原生覆盖/后台时停掉动效和自动轮播。没有持续移动整个4K壁纸。

## 预设应用

[目录](../public/launcher/app-presets.json)列出哔哩哔哩、腾讯视频、爱奇艺、优酷、芒果TV、咪咕、Netflix、Apple TV、YouTube、Disney+、Plex和Kodi。目录中的包名是候选匹配，固件与商店变体还需真机核对。

只自动填充从未设置的四个常用位置，遵循目录顺序、去重包名；不覆盖自选应用、排序或显式移除的空位。添加/替换/向前后移动沿用本机管理。已安装且可启动的应用由PackageManager提供正式图标；优先TV启动Activity。图标经本机精确白名单路径提供，不向网页开放包名启动能力。

随包预设使用文字色块，不声称是官方logo。未安装项只提供安装指引，应用的地区、账户和订阅仍由应用负责。浏览器截图中的安装状态和图标文字是合成示例，不是电视检测结果。

## 摘要

照片、指标、未过期生活数据、留言、今日日程和已保存NAS连接可以生成摘要。NAS只显示保存连接数量/已绑定相册状态，不把“已保存”冒充“在线”，不向WebView发送服务器地址、路径和凭证。

没有内容就隐藏；一项静态；多项每12秒翻页。读取家庭数据的5秒轮询不会重置翻页计时。焦点在摘要内、打开弹窗、翻到别屏、应用失焦或进入后台时停轮播。减少动态效果时静态显示。设置支持自动、静态、隐藏；家庭授权失效清除家庭内容，独立的本机NAS摘要可保留。

[Hub接入预留](HUB-DISPLAY.md)包含账户与展示约定，目前并未接通闭源产品数据。

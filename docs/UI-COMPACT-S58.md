# S58 · 页面缩减与尺寸重构

本地开发中的 UI 迭代，当前发行包仍为 v19 / alpha.16。未构建或上传新 APK。用户承担的小米真机和 WorkBuddy 客户端验收不以本页的软件检查替代。

## 可见范围

家庭页只保留相册、今天的安排、留言。首页保留一个按配置出现的摘要区；没有配置就隐藏。工作台保留安排、留言、相册、家庭影院、设备五栏，撤下独立指标编辑、生活连接编辑、场景切换与场景包导入导出。已有数据与后台能力不删除。

电视版保持深色玻璃，表单和浏览器兼容页提供实色回退；手机/电脑管理页继续使用清亮主题，不把电视字号搬到手机。简单标签替换装饰口号。

尺寸为1920×1080的 launcher 设计坐标；原生使用 dp/sp，不能把浏览器截图当作原生密度验证。标准首屏时间保留大字号，电视按钮仍有清晰焦点，不以缩小为目的压低可读性。

历史宣传片 `/film` 是既有创作素材，不改写为本轮产品实现；本轮录制使用上述真实开发页。系统安装器、原桌面、小爱及米家界面归原系统管理，不替换其 UI。

## 验证

- `node scripts/browser-s58-ui-qa.mjs`：首页、折叠、翻屏、父母入口、摘要详情、设置/壁纸/预设、配对、返回焦点，以及960/1280/1920/3840/390宽度。
- `node scripts/browser-s58-family-qa.mjs`：真实本地服务登录/写入，精简栏目、旧数据保留、刷新和校验错误保留草稿、兼容家庭失效清除，320至1920各宽度。
- `node scripts/browser-s58-cinema-qa.mjs`：合成Jellyfin/TMDB来源、真实本地HTTP与VP9解码、收起/唤回/返回、直播直进、爸妈版与多宽度。
- `node scripts/browser-lite-qa.mjs`：禁用 fetch/SSE/WebSocket 的兼容模拟；实际 stdio MCP 写入、轮询、回执、撤销。不是实际旧WebView。
- `node scripts/browser-s58-nas-setup-qa.mjs`：真实页面/WebCrypto/服务、Java接收端、丢失响应查原回执、错指纹拒绝；保存结果为合成确认，不是真实NAS。
- `node scripts/browser-s58-support-qa.mjs`：指引、检查、NAS未配对页，版本预览与目录跳转；方向键和原生按键桥接展开/收起说明。
- `node --test tests/local-agent.test.mjs tests/server.test.mjs`：19项通过，授权、冲突、幂等、撤销和新展示回执。
- `node scripts/check-native-compat.mjs`：使用持久 `.android-local` 工具链，两版 Android 35 API 编译和原生策略检查；不组装APK。

本轮新增回执 `presentation=family-v2`、`sceneApplied=false`、`sections=[photos,events,notes]`。`scene` 留作旧协议偏好，不意味着新家庭页显示了该场景。Agent 工具说明已明确这个区别。

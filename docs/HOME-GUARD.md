# 默认桌面与开机

仅面向小米电视 Android 8+。这是可撤回的桌面接管，不是刷机，也不替换系统固件。

## 在电视上开启

1. 开视设置第一项“默认桌面与开机”→“设为默认桌面”。系统允许时，选择开视并设为始终使用。
2. 如果小米固件仍把 HOME 交给原桌面，开启“桌面守护”，按提示在系统辅助功能中授权“开视桌面守护”。设置显示“等待授权”“等待系统连接”或“已连接”，不以开关开启冒充授权完成。
3. 复测冷开机、待机唤醒、从其他应用按 HOME、首屏返回确认。每项都需在实际机型确认；辅助功能被固件关闭时，不会偷偷重授权限。

默认桌面优先由系统处理。可选守护只在真实解析到的小米系统 HOME 窗口出现时拉起开视；部分固件提供的 `homekey` 系统事件也用于 HOME 返回。服务不读取屏幕内容、通知、使用记录，不过滤遥控器键，不接管 HDMI、播放器、音量或语音键。没有通知监听、悬浮窗或系统应用停用操作。

## 回到小米桌面

首屏按返回并确认，或打开“返回原桌面”，本次允许原桌面留在前台，不会立刻被守护拉回来。主动从应用入口打开小米桌面也放行。重新打开开视、下一次有效 HOME 事件或进入待机后重新守护；固件若不提供 HOME 事件，需从应用列表打开开视。

永久恢复：设置→“默认桌面与开机”→“恢复小米桌面”，先关闭守护，再在系统页面把小米桌面选为默认；辅助功能中可撤销开视授权。开视仍为默认时，不会直接撤掉唯一的 HOME 候选。原桌面、小爱、米家与账号组件保持原状，实际共存仍需真机复测。

## 辅助功能入口被固件隐藏

官方示例以 WorkBuddy 为操作助手：用户先在电视打开“桌面守护”，再明确授权 WorkBuddy 为本机开视开启辅助功能。用户需自己打开电视调试并确认电脑连接；脚本不能绕过该确认。

```bash
python3 scripts/kaishi-home-accessibility.py --serial 电视的ADB序列号 status
python3 scripts/kaishi-home-accessibility.py --serial 电视的ADB序列号 grant
# 撤销时只移除开视，不覆盖其他辅助功能服务
python3 scripts/kaishi-home-accessibility.py --serial 电视的ADB序列号 revoke
```

该工具不负责开启应用内开关，不改默认桌面、不禁用任何系统包，不改 density/分辨率，也不安装常驻电脑服务。必须明确指定设备；默认只读。授权后电视设置应显示已连接，再按 HOME 实测；设置被拒绝或回读不符时报告失败，应复核电视状态，不宣称成功。操作结束可关闭电视调试。

## 关于开机广告

进入 Android 桌面后的推荐广告，通常可通过替换桌面避免。更早的固件开机视频在开视启动前播放，普通 APK 不能保证消除；本版本没有集成禁用广告包、固件修改或通用“去开机广告”开关。部分机型需厂家提供关闭渠道。不能以新首页无广告推导所有开机广告已去除。

# 小米电视兼容检查

目标是保留原系统使用习惯，额外提供家庭信息、NAS和个性化入口。Android 8+只是安装下限，不代表每台小米电视都已适配。当前没有小米实体电视验收结果。

## 默认作为普通应用

从源码 v11 起，安装后不注册可用的 HOME 候选，不申请开机启动，也不替换原桌面。标准版与爸妈版各有一个默认关闭的 HomeEntry。需要用开窗作为桌面时，在「默认桌面 → 允许本版作为桌面」确认开启，再由系统选择；固件不支持更换时继续作为应用使用。

「移除本版桌面候选」只停用本版入口，并提供系统桌面选择。不会清除其他应用默认项、停用小米桌面或强制写入系统默认值。移除当前默认桌面后，各固件可能显示选择器或回退桌面，不能保证自动恢复到用户原先的选择。「返回原桌面」仅打开原桌面，不改变默认项。

**v10及更早版本升级：**以前 MainActivity 自带 HOME 过滤器，新版改为独立别名。原先把开窗设为默认桌面的用户需要重新主动开启和选择。新别名默认关闭；此前保存的家庭服务、NAS和首页样式不因此清除。不要为升级先卸载。

## 原生生态边界

| 项目 | 实现与当前证据 | 小米真机验收 |
| --- | --- | --- |
| 原桌面与 Home 键 | 独立可撤销 HOME 别名；仅系统公开设置；Android TV模拟器可核验候选与默认解析 | 安装、升级、开启、移除后分别按 Home；检查原桌面、系统设置和卸载后的默认行为 |
| 小爱语音键 | ASSIST、VOICE_ASSIST、SEARCH、HEADSETHOOK走系统；无麦克风或热词权限；有源码/API与浏览器契约检查 | 原桌面和开窗分别长按、松开，检查持续监听、语音搜索和焦点返回 |
| 远场与待机唤醒 | 由硬件和原固件负责，无常驻唤醒服务 | 原系统支持的条件下对照测试；不能用模拟器通过替代 |
| 音量、电源、输入源 | 没有接管这些按键或更改电源设置 | 实体遥控音量/静音/电源、HDMI切换与返回；原生浮层应能显示 |
| 小米账号 | 只打开原系统公开账号设置；不读取、同步或接管账号凭证 | 已登录状态、账号设置可达性、切回原系统后状态一致 |
| 米家 | 自有HA通过官方Xiaomi Home独立授权；只读实体、手动选择分享；不调用家电控制 | 原有米家设备和自动化仍可用；撤销HA授权后读取失败；检查分享快照过期与移除 |
| 播放中断 | NAS窗口/音频焦点丢失时暂停，不自动续播；已有纯Java合成端口验证 | 实际播放时唤醒小爱、切应用、待机；检查暂停与主动恢复，无重叠声音 |
| 两版与本地数据 | 独立包、独立偏好；不读取其他应用数据 | 覆盖升级保留家庭/NAS设置、两版独立；返回原系统仍可用 |

源码v13的Manifest申请INTERNET、REQUEST_INSTALL_PACKAGES与REQUEST_DELETE_PACKAGES，后两项仅用于人或已授权WorkBuddy发起原生安装/卸载确认；不是静默安装或删除权限。应用无账户读取、无障碍、系统设置写入、开机广播接收器或后台服务。私有 debug 合并清单允许 HTTP 供内测，不能把它当正式安全配置；家庭凭证交接仍要求可信 HTTPS。

## 实机记录方法

先在原系统记录同样操作的结果，再安装新版对照。填写型号、固件、Android/WebView版本、遥控器类型、测试包版本与签名；不采集序列号、账号、家庭录音或NAS口令。分别记录通过、失败、未测，任何默认桌面无法返回、语音被吞或原系统账号异常都应阻止公开推荐该机型。

无须先启动电脑家庭服务，即可检查普通应用启动、原桌面、小爱按键和系统快捷入口。米家分享与家庭内容另按 [米家接入](XIAOMI-HOME.md) 检查；NAS按 [NAS指引](NAS.md)。本页是验收清单，不是小米官方认证或全机型承诺。

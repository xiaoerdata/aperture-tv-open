# 可选家庭影院

定位是用户自己家庭的片库入口，默认关闭。管理员可在工作台开启、选择已配置的媒体库、导入/替换/移除 M3U；电视与已连接家庭成员只读浏览播放。媒体目录被选中意味着其中所有可索引视频对全家可见。

## 三条已实现路径

- **电脑/NAS共享目录**：递归索引 mp4、m4v、webm、mkv、mov；后缀能被索引不代表客户端能解码。跳过隐藏文件与符号链接，播放前检查真实路径仍在批准目录内。支持 HEAD、单段 Range、suffix Range 与进度拖动。
- **Jellyfin**：固定服务地址、用户和限定 libraryId，服务端鉴权列举前200项并代理静态原始视频流。没有转码协商、字幕切换、海报代理、多音轨选择、观看进度回写或 DRM。
- **M3U直链/HLS**：用户导入64KB、最多100项的清单，只有服务器 allowedOrigins 精确白名单中的 HTTP(S) 来源可用。HLS 主/子清单、分片和密钥 URI 代理成同源的临时不透明地址。hls.js 作为本地安装依赖服务；不远程加载脚本。禁止跳转，不自动扩大到 CDN 域名。

本机测试浏览器缺少 H.264 解码能力，因此实际解码验证使用 VP9 WebM 和 VP9 fMP4 HLS。真实 Xiaomi WebView 的 H.264/AAC、HEVC、4K、音轨和长时间播放仍需硬件验收，不能把浏览器验证说成全格式支持。

## 配置

将 examples/media-config.example.json 复制到私有目录，填入自己维护的来源。使用 APERTURE_MEDIA_CONFIG=/private/media.json npm start。Jellyfin 凭证放环境变量，不写在 URL、源码或前端。单进程家庭服务器应以只读权限访问媒体目录。

示例中的 Jellyfin userId/libraryId 需换成真实值，tokenEnv 对应最小权限家庭专用用户的令牌。不要使用管理员全库密钥代替共享范围。URL 可带反向代理 base path。网络 HTTPS 与可信内网配置由管理员管理；WebView 只请求开窗自己的 origin。

手机：家庭影院 → 勾选开启 → 选择来源 → 保存。电视页出现「家庭影院」，或直接访问 /cinema。媒体库尚未配置时有明确空态。

## 电脑局域网、网盘与现有播放器

电脑本机目录可以直接作为路径。SMB/NFS/WebDAV/个人网盘先由主机挂载到本地目录，或交给 Jellyfin 管理，再接入。挂载只读，使用独立家庭共享文件夹。当前没有自动扫描局域网、网盘登录/二维码、DLNA discovery 或电视端 smb:// 协议。

参考了 [FongMi/TV README](https://github.com/FongMi/TV) 对浏览/播放/直播的能力划分，以及 [Jellyfin 网络文档](https://jellyfin.org/docs/general/post-install/networking/)。没有复制它们的界面或代码。FongMi 的爬虫扩展是另一种执行机制，本项目不解释任意 TVBox JSON、JAR、Python、QuickJS 或第三方解析脚本；现有播放器可经 Android 原生应用菜单打开，仍由原应用管理自己的配置。这里没有提供解锁付费内容或绕过 DRM 的功能。

## 授权、资源限制和撤销

最多12媒体库、每库200条、深度5、访问5000目录项；播放索引4096项，HLS引用4096项/1小时。最多4同时播放、2并发目录读取。关闭影院、移除源、删除频道或撤销会话后，新请求立即拒绝，现有流每2秒重新检查；页面每5秒复核状态。已经缓冲的媒体无法瞬间从设备内存删除。

媒体传输不在响应中返回源 URL、服务器文件路径或 Jellyfin token。原文件只读；所有请求均需家庭会话。公网带宽、安全证书、NAS权限和容量管理依然是部署者职责。失败库显示局部失败，已索引其他库继续可用。

二次开发入口：server/cinema/{config,service}.mjs；public/cinema/{studio,player}.js。配置与清单写入复用 board service 的 revision/幂等，不另建业务数据副本。M3U原地址存私有 state.mediaChannels，board 不包含它们。


## 爸妈版与自动检测

爸妈版首页只留「看电视 / 看电视剧 / 看电影」。家人在 `/studio?tab=cinema` 开启影院、选择媒体库并指定分类：Jellyfin自动区分Episode和Movie，共享目录默认电影/家庭录像，也可指定为电视剧。M3U的 `group-title="电视剧"` 或 `group-title="电影"` 对应剧集/电影，未标分类按直播处理。这里统一配置的是开窗的媒体库与标准M3U；不远程修改第三方影视仓应用的内部配置。

影院开启、来源/分类保存、清单替换或移除后自动检测；服务启动时读取现有配置，之后每15分钟复查。管理员可点「现在检测」，并发请求合并、30秒冷却，最多两项同时检测；关闭影院/来源变更/服务停止会取消旧网络任务，旧结果不写回。检测不改变播放清单，也不自动删除暂时失效的频道。

网络请求单项6秒，禁止跳转、限制媒体样本和清单大小，HLS逐项核对origin再读取首个分片。来源需要登录、超时、返回网页、跨未授权来源与无法识别的容器分别提示。共享目录检测限制4层/300项并只读探查首个候选文件；底层网络挂载的阻塞仍取决于操作系统。Jellyfin检测固定用户/库，读取1项。健康报告不含URL、路径、令牌。

「媒体库可访问」「媒体数据可读取」分别表示有限探查结果；不代表完整影片、所有分片、加密密钥、编码、音轨或电视解码通过，也不是持续可用保证。浏览器验证使用合成VP9片段；家里的真实直播源、4K/HEVC与长时播放待实机验证。检测读接口与触发接口仅管理员可用。

复现：`node --test tests/media-health.test.mjs tests/cinema.test.mjs`、`npm run qa:cinema`。后者需ffmpeg，可用`FFMPEG_PATH`指定，记录在docs/verification/parents-media.json。

家庭影院播放器要求WebView89+（ES模块和本地HLS依赖）。Android8+不是WebView版本保证；原生外壳在旧内核时明确提示更新或回原桌面，避免打开空白媒体页。轻量家庭信息屏仍可在较老内核运行。

首次打开或设备被撤销时，可直接点影院页的「连接这个家」申请只读码，家人批准后回到原来的直播/电视剧/电影列表。连接保存在HttpOnly会话中，无需每次输入；过期主动重连。此流程复用既有家庭viewer授权，不把管理口令放进电视，也不扩大Agent能力。


## Android 原生 NAS 直连（源码v6）

[NAS模块](NAS.md)直接在电视访问SMB2/3与HTTPS WebDAV，不需电脑挂载；入口位于影视仓、工具与相册。它与本文Node服务器片库分开，可将当前NAS目录指定为爸妈版电影/剧集入口，或从标准版选择片库；不合并海报/搜索/自动源检测，也不复用服务器或WebView中的凭证。小米仅限最新Xiaomi智能存储，五类目标机型仍待真机。不要把上面的“先挂载”解释成原生直连实现。

# v29 · 播放与遥控整理

版本：v29 / `0.2.0-alpha.26`，仅适配小米电视、Android 8+，继续为Alpha。标准版和爸妈版沿用v18起的包名与发行签名，可覆盖更新v18—v28；v17继续并存。

详情选线直接决定主播放；分享页、HTML/JSON与解码失败的线路按同一集依次回退，播放器可直接换线，保留进度和原始观看记录。没有匹配集数时不猜播其他集。媒体读取单次最多15秒，串行尝试。

片单固定五列，左侧栏始终可见。选集保留完整长标题、等高行和每20集分组；上键回播放，下键进入线路与集数。确认键打开频道或选集，点播左右调整进度，直播上下换台。修复更多菜单首行、来源弹窗第五项裁切；根首页返回原桌面后移除开视任务，不修改系统默认HOME。

首页去掉重复入口；新增只读HTTPS留言源，Agent更新文件、电视显示和按时播报。源文件有128KiB/100条上限、前台60秒刷新、离线缓存及过期处理，见[WorkBuddy留言源指引](MESSAGE-SOURCE.md)。自动屏保仅在首页前台按开关保持亮屏，离开即释放，不抢占其他应用。发行相册继续关闭，开发代码与旧数据保留。

## 验证与待测

S76标准版、爸妈版各27条Android系统输入断言通过，使用UiAutomation注入方向键和系统触摸；4组首页浏览器任务、13组天气/屏保任务、协议/消息与服务回归通过。两版ARM32/64 release及Lint通过，零错误，分别保留60/61项警告。APK签名、随包首页资源、品牌像素、发行DEX和源码摘要已绑定到[最终软件回执](verification/s76-summary.json)。

Android28软件模拟器使用旧WebView的原生恢复首页；上述检查不能代替小米真机。小米原桌面、小爱/米家、玻璃首页Android亮屏策略与OEM屏保、中文TTS、WorkBuddy实际上传文件、至少10部外部点播的成功率和两小时持续播放仍待维护者验收。未做SAR修正，不宣称解决所有直播黑边；测试使用合成目录和已授权短片，没有预置影视来源。

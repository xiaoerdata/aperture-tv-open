# v18 并存安装

本项目仅适配小米电视。本次v18 / alpha.15采用新包名和新发行证书，与v17并存，不是覆盖升级。

1. 保留旧开视，不卸载、不清理数据；旧安装包继续在v17发行页保留。
2. 下载v18对应版本并核对SHA-256。标准版包名 `org.zhixiaoce.kaishi`，爸妈版 `org.zhixiaoce.kaishi.parents`。用原系统安装器安装。
3. 从应用列表打开新版。标签分别是“开视”“开视·爸妈版”，可在系统应用信息中核对包名与versionCode 18；新版图标为黑底白色开口视窗。
4. 新版重新配对家庭服务，授权自己的WorkBuddy；旧版凭证不会自动读取或撤销。无需再用的旧授权可在原家庭服务的授权界面撤销。
5. 在新版重新添加NAS、来源及常用应用。不要把密码、旧二维码或凭证放到聊天或公开问题中。本版没有一键导入旧应用私有数据。
6. 先检查方向键、四个观看入口、NAS和“原桌面”。默认HOME候选关闭；不主动修改小米默认桌面。

原桌面候选排除新旧四个开视包；选择后启动原系统入口，再结束开视任务。固件限制导致打不开时可重新选择原桌面或进入系统设置，不要求重启作为正常操作。小爱远场、待机唤醒、小米账号、米家与默认桌面行为仍需在具体电视复验。

发布附件使用非debug release构建，但产品仍是Alpha测试版；构建类型不等于稳定性承诺。新发行签名在私有持久目录保管并有独立副本，不随源码分发。

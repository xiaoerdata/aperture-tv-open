# v30 · 风景首页与片单整理

版本v30 / `0.2.0-alpha.27`，仅适配小米电视、Android 8+。标准版和爸妈版保持v18起的包名与稳定发行签名，可覆盖更新v18—v29；v17继续并存。产品仍为Alpha。

- 首页继续保留风景摄影和深色玻璃。旧网页内核、手动本机模式或渲染异常也采用本机风景首页，有时间日期、四个观看入口及向下应用/工具；爸妈版已配置的常用应用保留首屏。
- 海报墙改四列，保留年份、类型与来源评分。重复图片合并加载，修复后排海报任务被丢弃的问题。
- 选集栏约占屏宽33%；短标题用紧凑网格，长标题完整换行，每20集分组。换线始终匹配原先选中的集数，保留进度，不再因中间线路不完整而跳集。
- 触摸第一次点击即执行；远程目录超时只影响该来源，本地片单可直接切入。
- 原生资源包支持混合电影/电视剧/综艺，每项明确栏目；补充常见海报/简介别名与数字资料，保留旧字段。见[资源包](RESOURCE-PACK.md)。
- 新增可选[局域网控制](LOCAL-TV-CONTROL.md)：六位码、核验证书、电视确认后授权30分钟。WorkBuddy可读取开视自身界面、发送内部方向键、取得不含视频的自身截图、推资源包并探测首帧。默认关闭，不提供匿名读取、系统注入或跨应用截图。

直播频道栏支持左右切分组、上下选择、确认换台；双向首尾循环，浏览分组时保持当前频道播放。两版均用系统注入方向键补测，单一分组的来源不会产生其他分组。

确认键打开频道/选集、点播左右调进度、直播上下换台、原桌面与小爱入口继续保留。相册仍从发行版关闭，代码和旧数据保留。没有预置影视来源，不增加系统权限或改变默认桌面。

## 软件证据与真机边界

两版ARM32/64发行构建、签名和随包资源逐项核对；发行检查零阻断错误，警告和实际输入回归以[最终软件回执](verification/s79-summary.json)为准。浏览器主玻璃首页两版1920/1280任务、领域/资源契约与证书先验测试单独记录。原生测试在Android28软件模拟器1920×1080、密度320执行，不是小米机型验收。

小米原桌面、小爱/米家、OEM屏保、中文TTS、真实NAS/WorkBuddy客户端、同网发现与推包耗时、至少10部外部点播成功率和两小时耐久仍由维护者测试。不能以本轮检查宣称所有来源和机型稳定；不把接口存在当作这些验收通过。

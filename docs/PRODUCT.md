# 开窗：家庭共享屏产品设计

日期：2026-10-23。用户确定：最近一两年的标准小米电视，按 Android 8+、16:9 设计；首要任务是家庭日程、留言、相册、数据；作为智小策首个开源项目，并记录到小红书。

## 体验主张

开窗是一块“家庭共同维护的客厅画布”。电视负责远距离阅读与展示，手机负责输入、上传、安排和设备管理。核心价值是家人能够一起改变屏幕，而不是独立欣赏一个作者预先做好的屏保。

首屏一眼看见三个问题的答案：现在几点、今天还有什么安排、家人想告诉我什么。照片在视觉上占据最有吸引力的位置；数据在底部摘要常显，可以切换到数据群岛深入看。主操作是手机添加一条内容并在电视上得到真实反馈。

默认密度：一条留言、一张照片、今日全部日程的可滚动列表、前三个家庭数据。一个普通家庭不必配置一套大看板才能开始。示例模式与真实家庭空间明确区分；空态不假装已有家庭数据。

## 原创的四个抓手

1. **同一内容，三种空间。** 日光庭院强调今天与留言；记忆展厅放大照片；数据群岛将目标进度形成山体。切换保留今日时间/日程的空间位置，降低家人找信息的成本。
2. **拱窗作为内容容器。** 标志、相册裁切、电视场景和视频封面形成统一识别。用明亮青绿、墨绿文字、橙色太阳建立视觉，不模仿 tvOS 应用图标阵列。
3. **遥控器只做小决定。** 切窗景、换照片、暂停、沉浸、返回。输入在手机完成；设备权限区别于成员编辑权限。
4. **分享一扇窗，不分享整个家。** JSON 场景偏好包可以公开传播，家庭数据、照片、名称、凭证不随包导出。开发者可以增加独立场景模块，普通用户不用安装任意第三方脚本。

以上是本项目的具体取舍，不宣称“全球首创”或“没有同类”。已有 Launcher 也可能包含壁纸、相册、组件等能力；差异主要在家庭内容闭环与统一视觉语法。

## 三个场景

| 场景 | 内容职责 | 动效与交互 | 诚实边界 |
|---|---|---|---|
| 日光庭院 | 一天安排、最新优先留言、当下照片 | 浅层地景缓慢起伏；清楚焦点；进入沉浸 | 日光与飞鸟是程序艺术，不是天气和天文实况 |
| 记忆展厅 | 让上传照片成为主角 | 照片扩大成拱窗；遥控器“下一张” | 手动翻页，不冒充已实现自动策展或识别人脸 |
| 数据群岛 | 家庭数值与目标 | 山体高度单调对应完成比例；数值与来源常显 | 含固定艺术基座，高度最大100%，超额完成继续以数字显示；不是严格科学柱状图 |

动画预算：Canvas 2D，每秒最多24次绘制，像素比上限1.25；不引入 WebGL/大型三维引擎。后台停止请求动画帧；手动暂停和系统减少动态偏好有效。电视性能仍须真机测量。

## 内容模型与协作

一台自托管实例对应一个家庭空间，所有已授权家人共同编辑。管理员可以审批连接和撤销设备；编辑成员可以新增、完成、删除家庭内容并更改窗景；电视只能读取。连接码是短期申请，不单独构成授权，还须管理员批准和申请端持有的秘密领取。

写入同时携带 revision 和幂等键。不同家人同时编辑时后一份收到冲突，保留输入并请求显式刷新；网络超时重试沿用同一请求键。收到“已保存”之后回读失败也明确告诉用户保存已成功。

照片需服务器成功解码，去除 EXIF，长边缩放到1920并重新编码为JPEG。拒绝 SVG、任意网页、HTML和外部脚本；当前也不抓取用户提供的 URL。照片链接本身不授予访问权。

## 分阶段开放

- **本次 alpha：** 单家庭自托管、三场景、手机工作台、配对、真实同步、Android源码、场景包、文档与素材。
- **真机候选：** 明确型号/系统/WebView、安装签名APK、遥控器按键和3米阅读测试、离线与休眠恢复、连续运行2小时、内存/帧时间测试、退出与卸载验证。
- **社区第一版：** 公共Git仓库、可下载且校验的APK、CI、三方贡献指南、兼容设备实测表、Issue模板；每个未经测试设备只标“待测”。
- **后续：** 成员邀请细化、日历订阅、可撤销的上传分享链接、图库清理、场景市场、更多数据适配器、电视本地加密缓存。按需求与验证推进，不把规划项放进功能列表。

官方云托管与自托管开源核心分开。云托管需要多租户、账号与独立产品权限，不把当前单家庭服务直接并入生产 Hub。

## 人和 Agent 两条任务流

人：连接家庭 → 手机添加内容 → 电视读取更新 → 家人调整 → 管理员撤销设备。

未来受托 Agent：在 Hub `/agent` 完成受鉴权连接 → 发现已授权能力 → 读取家庭当前 revision → 按授权创建日程/留言或数据 → 使用幂等键写入 → 独立回读确认。日程批量删除、对外发布和设备授权不自动赋予 Agent。

自托管alpha已提供受限本机Agent入口：场景/内容编排，以及v8可选的加密NAS配置交接，见[WorkBuddy](WORKBUDDY.md)与[NAS交接](NAS-SETUP.md)。托管机器入口仍未开放，需要每次重新校验身份、令牌、独立Agent权益、产品权限、scope、资源归属、撤销及配额；复用现有Hub运行时及本项目领域服务，不能拿自托管管理口令冒充付费MCP授权。私有草案位于 `integrations/`，公开导出排除。

# 适配范围

**本项目仅适配小米电视。** Android 8 / API26 及以上是最低技术要求，不能据此认为所有小米机型、固件或WebView都兼容。

不把其他品牌Android TV、电视盒子、手机或电脑列为支持设备。开发时使用Android TV模拟器和浏览器验证协议与布局，这些结果不是支持型号。源码采用开放许可，第三方可自行修改，但其适配结果不作为本项目的官方承诺。

开视是运行在原系统上的家庭入口应用，不是小米官方ROM或官方认证产品。原桌面、小爱同学、小米账号与系统安装确认继续由原系统处理。只有对应型号现场测试完成后，才在兼容表标记该型号结果。

NAS是家庭资源服务，与电视品牌范围不同：小米仅面向最新Xiaomi智能存储；海康、绿联、群晖与TrueNAS按协议和具体固件分别验收。不因此扩大电视支持品牌。

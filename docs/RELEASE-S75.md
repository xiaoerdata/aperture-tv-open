# v28 · 频道与选集

版本：v28 / `0.2.0-alpha.25`，仅适配小米电视，Android 8+，继续为Alpha。标准版和爸妈版沿用v18起的独立包名与稳定签名；从v18—v27覆盖更新保留配置，v17继续并存。

本版关闭发行相册入口和NAS照片预览，开发代码、旧照片及目录设置保留。家庭分区保留安排与留言。影片详情移除相似推荐；选集改为两列宽行、原始完整标题和20集分组，线路与分组在原页切换。

播放画面确认键打开频道或选集；点播左右控制进度、直播上下换台。列表浏览时保持展开，返回先关闭列表；播放/暂停仍可通过工具栏或媒体播放键操作，点播上下/菜单进入工具栏。频道选中状态独立于系统焦点，确认键按同一页面的按下和抬起配对。

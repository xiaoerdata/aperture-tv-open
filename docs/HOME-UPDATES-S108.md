# 相册、应用与片单排序

> 本文保留该阶段的开发记录，改动已合入v43；安装与验收范围见[v43说明](RELEASE-V43.md)。

本轮为标准版源码更新，未打包、未上传新版本。现有 v41 发行和 v42 本地候选不包含本轮改动。爸妈版暂停。

- 相册页的“确定 · 相册设置”提示显示 10 秒后隐藏，方向或确认操作会重新显示。按钮继续响应确认键；离页停止提示定时器。
- 单张照片上传上限为 20 MiB（界面显示 20 MB）。手机预检和电视 HTTP 接收同步调整；现有图片像素数、相册总量和存储余量限制继续生效。
- 第二屏独立保存最多 128 个应用。选择“添加应用”后可多选，保存后直接回到第二屏；已有项保留顺序，新选择追加。移除勾选不会卸载应用。首屏四个快捷位置独立管理。
- 第二屏电视布局为八列，方向键在列表内滚动，首排向上回首页；原生列表末排向下到工具区，再进入相册。图标居中、名称在下方，使用本机图标及已有品牌预设。
- 相册屏保取消照片透明度和黑色渐变遮罩。左下依次为时间、日期、天气；保留文字阴影，其他屏保的遮罩不变。
- 电影、电视剧、综艺的片单左侧新增“排序”：默认“最新时间 ↓”，可选“豆瓣评分 ↓”。未知日期或评分在末尾，同分按时间；相同键保持来源顺序。

外部资源站按当前已加载的影片排序，继续翻页后合并重排，不代表服务端全库排序。豆瓣评分只接受来源明确标注的豆瓣评分或专用字段，普通未注明来源的评分和 TMDB 分数不会作为豆瓣评分。缺失数据不联网补造。

资源包的节目资料可提供 `updatedAt` 和 `doubanRating`，放在条目顶层或 `metadata` 内；相同字段重复时必须一致。`updatedAt` 支持 ISO 日期时间、日期、上海本地日期时间及秒/毫秒时间戳字符串。`doubanRating` 支持 0—10 的数字或既有文本评分形式；0 和无法识别的值不参与有效评分排名。TVBox/MacCMS 读取对应更新时间和专用豆瓣字段。

## 验证

执行 `CHROMIUM_PATH=/opt/google/chrome/chrome node scripts/s108-home-updates-test.mjs`：

- 18 项应用持久化、安全启动标识、日期及豆瓣来源与资源包检查。
- 24 项既有 HTTP 传输回归，包括分块、授权、撤销、刷新异常与结构化错误。
- 18 项上传边界检查：13 MiB 分块、20 MiB 普通/分块接收，超限一字节拒绝。
- 浏览器验证 50/128 项应用、内部滚动、首尾翻屏、焦点恢复和图标居中。
- 假时钟验证提示 10 秒隐藏和遥控操作恢复；合成照片屏保的实际截图像素与原图 RGB 相同。
- 手机尺寸浏览器验证 20 MiB 发送、超限预检不发送；这一项使用合成字节和模拟成功响应，真实 HTTP 大小边界由独立回环测试完成。

实际看图时发现旧 `gallery.css` 仍将照片透明度设为 0.72 并隐藏天气，已移除冲突规则；修正后再次通过像素和布局检查。截图解码测试最初被页面 CSP 拒绝 data URL，改为同源测试图片，没有放宽产品 CSP。

原生 120 份 Java 源码定向编译及 29 项尺寸案例通过，未进行 Gradle/APK 构建。没有连接小米电视，原生多选对话框、图片解码与跨手机网络上传仍需真机验证。

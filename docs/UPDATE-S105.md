# S105候选阶段记录 · v41

本文记录发布前S105的本地候选阶段；后续发行状态见[正式发行说明](RELEASE-V41.md)。

标准版 `0.2.0-alpha.38` / versionCode 41，仅适配小米电视 Android 8+。爸妈版继续暂停。本轮是本地候选包，尚未推送到 GitHub；公开下载页仍指向 v40。

本地安装包：`artifacts/v41-candidate/kaishi-v41-standard-arm.apk`，55,363,900 字节；SHA-256：`247f682ac417ee6037cd2bca95f7fec5a824abb4981e78b3ffefbf14ae00e9b2`。ARM32/64，包名 `org.zhixiaoce.kaishi`，沿用 v40 的正式签名，可覆盖安装，不需要卸载或清数据。

## 改动

- 第二屏把应用图标和名称分开：图标在固定画框内居中，名称在下方，长名称不再挤偏图标。网页焦点框只围住图标区域；原生首页直接按容器中心绘制图标，不再依赖按钮的复合文本排版。
- 首页继续按实际窗口宽高取统一比例、标准版内容系数0.86；补充方向改变监听，并验证运行中从540p到4K、较矮窗口的变化。按钮、字体、图标一起缩放，不调整电视全局分辨率或density。
- 原生相册补齐本机生成二维码，旧WebView也可扫码上传。选“手机上传”并确认开启后显示二维码，10分钟后、关闭弹窗或离开相册时关闭上传；不自动启动上传服务。
- 第四屏和设置新增“扫码编辑留言”。电视显示二维码，手机在同一家庭网络中添加、编辑、删除本机留言。修改保存在电视私有存储；返回首页后可查看。外部HTTPS留言源保持独立，只读显示。
- 留言扫码入口需点击“生成二维码”，10分钟有效，离开页面后关闭。每次写入检查令牌和版本号，多手机同时编辑时提示刷新，保留手机当前草稿；最多100条，每条500字、整体128KiB。
- 天气页显示24小时气温曲线、降水概率和可左右翻动的逐小时预报；未来7天用对齐列表和可比较的最低/最高温区间表示。数据缺失时曲线留断点，不补造温度；断网时保留明确空态或过期说明。保留IP估算城市、搜索换城及来源署名。

## 本地验证

- 116份实际Android源码定向编译；标准ARM release实际构建成功，94.52秒。
- 229项源码/资源输入与候选包相符；包内含原生二维码和手机编辑类，不含测试注入类；签名与v40一致。
- 18项留言增删改、版本冲突、权限、过期与中途关闭检查。手机浏览器通过真实的本机回环HTTP服务完成增删改，不只模拟按钮；覆盖320/390/760px和44px触控尺寸。
- 原生二维码编码结果由OpenCV独立解码；没有使用外部二维码服务。
- 12组首页浏览器回归，另有运行中尺寸切换、第二屏图标中心、第四屏遥控进入编辑、天气曲线断点、逐小时遥控滚动、七日预报、城市搜索和断网空态检查。
- 过程中的一次Java字段初始化错误已修正；浏览器用例曾在城市刷新中读取临时不存在的标题、用固定100ms等待尺寸变化，已分别改为等待标题出现和实际视口报告。没有跳过失败断言。

回执见 `docs/verification/s105-phone-weather.json`、`s105-home-regression.json`、`s105-native-compile.json`、`s105-release-candidate.json`。截图位于 `docs/images/s105/`，使用合成天气、留言与应用配置，不是真机截图。

## 小米电视待验

没有连接电视，不能把上述本地检查当作已完成真机验收。安装v41后，保持原系统显示设置，检查第二屏图标是否居中；第三屏打开相册上传，扫描原生二维码并上传两张测试照片；第四屏扫码增删改留言，返回首页确认内容；天气页用遥控器查看24小时和7天、切换城市。二维码期间不要关闭对应电视页面。无关的系统桌面、小爱和NAS能力不在本轮宣称新验收通过。

# 留言源 v1

电视只显示内容、时间和播报；没有增删改留言的入口。标准版首页有摘要，安排与留言里显示完整内容。爸妈版可通过安排与留言查看。旧家庭留言数据保留，电视不再显示署名；配置新留言源后以新源为准，空列表会清空显示，不回退到旧留言。

在电视“设置 → 留言源”保存一个 HTTPS JSON 地址。断开时清除这个来源的本机缓存；“暂停播报”可单独关闭声音。地址不要包含用户名、密码或片段；不会附带家庭登录 Cookie 或 NAS 凭证。重定向最多3次且逐次要求 HTTPS。带查询参数的访问链接仅保存在电视私有设置，不回传给首页页面。

## WorkBuddy 操作示例

> 按开视留言源 v1 格式制作 family.messages.json，时区 Asia/Shanghai。每天20点提醒“晚饭后去散步”。使用稳定 id evening-walk。不添加任何署名。先运行 node scripts/message-feed.mjs family.messages.json 校验，再用我已授权的 HTTPS 文件服务发布至电视已配置的同一地址。后续按 id 修改或删除；删除时从 messages 数组移除。不要操作电视遥控器，不要更换账号或扩大文件发布权限。发布后回读该地址，确认数据和文件版本；电视同步情况单独确认。

示例：[family.messages.json](../examples/messages/family.messages.json)。格式检查只验证文件；上传仍使用用户自己的 Agent 和获授权的文件服务。本地开源版没有新增云账户、付费 Hub 入口或公开凭证下载。文件不是执行脚本，电视不会执行其中的工具调用或指令。

## 字段

| 字段 | 含义 |
| --- | --- |
| version | 必须为1 |
| timezone | IANA时区，默认 Asia/Shanghai |
| messages | 最多100条，整个文件不超过128KiB；空数组删除所有留言 |
| id | 1–96位字母、数字、点、下划线或短横线，同文件唯一 |
| text | 1–500字符，电视展示与播报的原文 |
| time | HH:mm 或 HH:mm-HH:mm；范围起点播报。留空只展示 |
| repeat | daily 或 once，默认 once |
| date | repeat=once 且有 time 时必填 YYYY-MM-DD，按文件时区解释 |
| tts | 布尔值，默认false |
| expireAt | 可选ISO8601，必须含秒与Z/UTC偏移，如2026-11-01T00:00:00+08:00 |

启动/回到首页时读取，首页前台每60秒读取，单次网络时限15秒。成功读到的列表替换缓存；网络失败使用上次成功缓存。同步删除通常下一次读取生效；网络延迟和断网时不能保证60秒。过期项即使离线也不显示和播报。没有内置人员、演示署名或缺省作者。

Android在首页拥有窗口焦点、中文TTS引擎可用、其他媒体未播放且未暂停播报时，只在目标分钟播一次。同一源、id、日期和开始时间去重；播报前落盘，重启不重播。错过分钟不补播；播报失败或中途离开不自动重试。更改文字不重播当天相同时刻。电视休眠或处于其他应用时不在后台唤醒/抢占。引擎不存在时仍显示文字；小米TTS引擎与系统音频行为需真机复测。

浏览器/家庭服务预览可通过 APERTURE_MESSAGE_SOURCE 配置同格式HTTPS地址，复用只读文件规则和60秒缓存；需要已有家庭会话。浏览器不做TTS，也没有电视的跨重启语音去重。原生简洁恢复首页暂不展示远程留言，需回到玻璃首页。

机器可读的字段说明见[JSON Schema](schemas/message-feed-v1.schema.json)。JSON Schema之外的日期、时区、时段顺序和ID唯一性仍由生产解析器检查；`tts`必须是布尔值，不能写成字符串"true"。

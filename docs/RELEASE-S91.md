# v35：返回原桌面专项补丁

标准版 `0.2.0-alpha.32` / versionCode35，仅小米电视Android8+。沿用v18起包名和签名，可覆盖升级保留配置。爸妈版暂停。

针对“HOME正常进入小米桌面，但开视的返回原桌面失败”：现在优先复用系统当前真实HOME分发；开视自身已为默认时，使用已发现的原桌面显式入口，防止回到自己。旧入口失败会继续尝试实际解析出的小米桌面与Launcher入口，保留真实Intent类别，成功后才更新缓存及结束开视。

全部尝试失败时，提示具体异常类别，失效入口不再被反复缓存。已授权ADB可用 `adb logcat -d -s KaishiHome:I` 查看固定route、桌面组件和异常类别。没有加入系统权限、停用原桌面或修改默认项。

[17项路由测试](verification/s91-home-return.json)直接运行生产代码，Android边界由替身提供；正式Android编译/签名和公开来源校验另见发行测试清单。本次开发机没有该小米真机，不能把路由测试说成系统已允许交接。默认显示与综艺等v34验收状态仍保持待测。

真机复测：HOME确认当前默认为小米桌面，再回开视点击返回确认，应直接进入同一系统桌面。开视设为默认后，再测试明确返回原桌面以及HOME回开视。若仍失败，记录新提示的异常类别和KaishiHome日志，不需要重置应用数据。

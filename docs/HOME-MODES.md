# 首页模式与旧内核兼容

v30保留玻璃首页，旧网页内核或渲染异常时改用本机风景首页。Android 8 / API26仍为安装下限；不由此推及更旧Android或全部小米固件。

## 两种首页

设置中的“首页样式”可选玻璃首页或本机风景首页。两者保留摄影背景、时间日期、四个观看入口与常用应用；本机版本直接由Android绘制，不创建首页WebView、不运行网页动画或家庭面板。爸妈版已配置的常用应用仍显示首屏。

玻璃模式可显示家庭内容轮播和网页动效。本机模式提供四套离线摄影壁纸和静态采样玻璃，壁纸偏好单独保存；不声称具有实时液态模糊或已与网页偏好同步。选择首页模式不清除家庭地址、配对、NAS、影视来源和应用快捷，不改变系统默认桌面。

## 自动路由

| WebView状态 | 首页 | 家庭内容 |
| --- | --- | --- |
| 无法确认 / 低于37 | 本机风景首页 | 不尝试家庭网页；原生NAS与已装应用仍可用 |
| 37–88 | 本机风景首页 | 保留已有ES5轻量家庭屏；网页影院需89+ |
| 89+ | 默认玻璃首页，也可手选本机风景 | 按家庭屏设置判断 |
| 当前Activity收到渲染进程退出 | 本机风景首页 | 本次不重建家庭WebView，避免崩溃循环 |

渲染进程退出的禁用仅限当前Activity；完全关闭再打开后重新判断内核。版本数字是路由规则，不等于相应内核/型号已验收。没有测得电视内存、功耗或帧率收益，不提供虚构性能数字。

v29及更早本机回退路径曾采用纯色按钮布局，这就是用户反馈的首页外观差异来源。v30改造见[反馈处理](V29-V30-FEEDBACK-S79.md)，软件与真机验证分开见[回执](verification/s79-summary.json)。下载以[版本索引](DOWNLOADS.md)为准。

# 本机首页读取家庭内容

v4的家庭数据只能从「家庭窗景」进入；本轮为标准版源码补上本机首页摘要与分区读取。爸妈版保持三观看入口与小快捷，不轮询家庭摘要。新版是否已打包以私有下载索引为准。

本机HTTPS页面只通过 `HouseholdProxy` 读取已配置家庭服务的 `GET /api/board` 与 `GET /media/<64位小写hash>.jpg`；CookieManager中的家庭会话仅在原生侧取出并过滤为 `aperture` Cookie，JS不获得地址或凭证。未连接、授权失效、更换服务或数据清除后，不沿用旧数据。静态资源仍遵循7项白名单，没有放宽为任意文件或任意HTTP代理。

代理拒绝跳转、非GET、主文档请求和路径变体；JSON最多1MiB、JPEG最多8MB。分离请求槽位、无缓存、失焦代次丢弃旧回复。连接/单次读1.5秒，读取阶段尽力控制6秒预算；等待槽位、慢响应头或系统DNS仍可能超过6秒，不宣称硬性总超时。家庭服务须可信。

相册按真实board的`asset`字段构建路径。照片、数据与信息每页两项，避免后续记录在电视画面外不可达；数据详情可遥控打开，刷新/过期同步更新，关闭及撤销时清空详情DOM并返回相应卡片。超过一页的内容用明确翻页，不自动滚动抢焦点。

复现：`npm run qa:household`，隔离Node家庭服务真实配对/撤销 + 生产Java代理 + 浏览器模拟本机HTTPS。包括规范化真实JPEG解码、五照片/六记录翻页、长详情、更新、过期、撤销和失焦停止轮询。报告[见此](verification/native-household.json)，画面为合成夹具，不是小米电视或真实家庭。原生WebView、固件Cookie行为及远场小爱仍待实机。

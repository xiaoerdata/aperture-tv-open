# 首页尺寸、相册第三屏与右侧设置

阶段记录：S101 当时仅完成本地源码，仍沿用 v39-r1 版本配置，未封装或发布。后续 v40 封装与上传见 [v40 说明](RELEASE-V40.md)。爸妈版不出新包，小米 85 QLED 和旧 WebView 的原生运行验收仍单独记录。

## 当前行为

1. 首页、应用、相册、留言依次为四屏；上下可以往返，常用应用保持展开。
2. 标准版首页内容相对原设计缩小 14%，壁纸仍铺满屏幕。网页按实际 CSS 视口缩放，不用设备像素比决定控件大小；原生首页按实际 View 可用宽高缩放。原生应用图标的 drawable 边界随容器同步缩放，避免小逻辑视口中的固定像素图标撑出按钮。
3. 翻到第三屏直接显示并轮播电视本机照片；不先进入管理、不自动开放上传。确定键打开相册设置，上下翻屏仍有效。空相册显示空态，退出页面/失焦后停止计时；从管理返回时重新读取本机照片。网页保留叠化、慢推和双幅模板，原生首页使用轻量叠化。
4. 网页设置、壁纸和添加应用统一为右侧窄面板，字号与行距收紧，长列表用遥控器上下滚动。遮罩覆盖整个视口，不跟随缩小的首页内容画布。
5. 原生设置面板以当前 Activity 的实际窗口宽高定位到右侧，宽度约 34%；相册管理约 42%。普通设置选择列表同步收紧字体；高影响操作的确认、权限确认仍保留独立交互。原生常用控件改为按窗口高度定尺寸，避免系统 density/override 不一致造成放大。

不修改电视的 `wm size`、`wm density`、系统字体、默认桌面或小爱设置。

## 设计取舍

延续现有 [深色玻璃规则](DARK-GLASS-DESIGN.md) 和 [遥控交互](TV-REMOTE.md)，以现有风景首页和设置面板作为对照：保留壁纸、时钟、四个观看入口和常用应用；减少控件在画面中的占比，不再扩张装饰卡片。相册先看内容，管理动作放在确认之后；设置沿右边展开，保留原画面的上下文。此轮是现有界面的比例与流程调整，直接用实际页面截图核对，没有新增生成效果图。

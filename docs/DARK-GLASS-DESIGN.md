# 深色液态玻璃 · 电视家庭主场

当前设计见[S48首页留白与翻屏](HOME-PAGES.md)。公开下载仍为alpha.13，S48本地设计尚未重新打包。下文保留S15/S16历史设计过程。

本轮按用户P17/P18/P19重新设计电视首页。父项目默认清亮的网页风格不覆盖用户对电视的明确要求；此处深色令牌仅属于开窗，不反向修改Hub视觉。

## 结构与交互

- 标准版八个一级入口：家庭窗景、电视直播、影视仓、家庭相册、今日数据、家庭信息、家庭工具、原生桌面。直播与影视保留既有本机应用绑定，原生桌面机制保持原样。
- 顶部分区：总览 / 相册 / 数据 / 信息 / 工具。总览同时显示照片、数据、留言与工具摘要；分区展开内容。返回键先关浮层，再退回总览并恢复对应入口焦点。
- 四页内容轮播：照片、数据、信息、工具。默认静止，明确开启后12秒切换；方向键、指针、触控、焦点移动、页面隐藏与减少动态设置均停止轮播。相册有多张授权照片时，每次重新进入照片轮播页前进一张。不替用户自动播放内容。
- 爸妈版保持三个大入口、大字、粗焦点、实底玻璃；隐藏复杂分区导航与轮播，只保留照片和留言摘要，点开可阅读完整内容。
- 玻璃用于导航、入口与浮层。深色承托、细高光边沿、有限模糊和全景层次共同形成材质。没有透镜折射或全屏实时着色器；不以视觉名称暗示已实现Apple系统渲染。
- 无backdrop-filter和减少动态时使用深色实底；可在入口设置中减少透明效果。遥控方向键、OK与返回复用现有原生按键名称契约。

## 内容与权限

HTTP模式通过既有受鉴权GET /api/board读取；使用既有会话，不新增账户、令牌或机器入口。30秒重新读取，前后台切换也刷新；失去授权或请求失败后清空摘要与展开内容。只接受同源白名单家庭图片路径。标题、来源和留言用textContent；不执行用户HTML。

展示数据的记录日期、来源与目标；家庭时区计算今天。过期生活快照隐藏值并显示待更新。未经连接不填写示例步数、天气、设备状态、已连接助手或在线设备数量。?demo=1明确标注合成数据且不读取家庭接口；TV离线资源页不访问家庭API或外网，也不尝试绕过原生固定动作列表。S17改用由本机精确拦截的虚拟HTTPS资源请求，修复新增背景与字体被旧白名单阻断的问题。

离线启动页的内容仍需要通过家庭服务进入已有家庭屏。新增主页不将凭证写入本地存储；本机仅保存原有透明偏好及已绑定应用设置。与真实WorkBuddy应用、米家账号和真实电视的连接状态不在本轮虚构。

## 复现与交付边界

- node scripts/capture-glass.mjs：8张1920×1080及390px实际Chromium截图；合成家庭数据，无凭证。
- node scripts/capture-lobby.mjs：真实浏览器操作录屏，四页轮播、入口浮层及爸妈版；不是电视实拍。
- node scripts/browser-launcher-qa.mjs：必要的内容/遥控/授权/布局验证。

本轮没有构建APK，没有替换private-preview/launcher-v3。v3旧安装包仍是此前浅色首页。浏览器截图不是小米电视实拍，也不能证明固件开机、原生Intent或旧WebView性能。深色全景在不同电视上的黑位、远距离文字、玻璃性能和爸妈版可用性仍待实机与用户观察。

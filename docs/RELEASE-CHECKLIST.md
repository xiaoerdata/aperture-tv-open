# 首次公开发布前的具体任务

P35与P47更新：已授权先公开Alpha用于测试，公共仓库为`xiaoerdata/aperture-tv-open`。以下稳定签名、硬件/WorkBuddy验收及生产部署是后续正式稳定发行清单；早期Alpha提供debug测试包，v18起提供独立发行签名的非debug包，当前版本和实测范围以[下载与版本](DOWNLOADS.md)及对应Release测试清单为准，不冒称正式稳定版。

本地开发交付已准备；以下不是已完成的发布声明。本项目仅适配小米电视，WorkBuddy与真机现场验收由项目维护者完成。

1. 由项目所有者确定公共Git仓库名称和组织、最终许可证与品牌名称。只导入OPEN-SOURCE-PREPARATION中审阅后的无Git历史源码目录作为公开仓库的首个提交；保留现有私有研发库，不直接切换它的可见性，也不推送上层工作区。
2. 在具备SDK的开发机编译并签名Android包；核对依赖、wrapper校验值和APK散列；完成明确型号真机矩阵。
3. 填写真实安装截图、恢复/卸载步骤和已测试设备表；发布说明保留未测试限制。
4. 若提供官方托管入口，先实现多租户和平台账号/产品授权；独立Agent权益按既有Hub规则执行，不用自托管管理员口令替代。
5. 首个互联网自托管实例上线时，用实际HTTPS域名验证手机外网访问、电视连接、上传、撤销、断网、备份恢复和边缘限制。
6. 建立真实安全报告渠道与社区Issue/PR入口。不要虚构Star、下载数、贡献者或设备测试数量。
7. 小红书上传使用本次媒体包；先审阅实际平台裁切与字幕，保留开发/示例标签。取得家人肖像、照片或声音使用同意后再替换测试素材。

建议第一篇先发布“为什么做与当前原型”，真机篇和开源发布篇等相应证据齐全后再发。

8. 按 WORKBUDDY 在真实客户端完成一次扫码、凭证保存、调用、回执、撤销与网络变化验证；确认HTTPS、代理源地址与边缘限制。浏览器模拟/协议测试不能替代客户端验收。
9. 审核每个实际安装的MCP连接器、媒体源和网盘方案的许可及权限；目录收录不代表已交付所有连接器，也不保证中国境内网络可用性。
10. 按 docs/process 逐阶段核对提示词→决策→实现→证据；保留失败和修复记录。小红书稿中的合成数据、原型、真机与正式发布必须清楚区分。先审阅素材，不自动上传账号。

# 电视本机相册

标准版首页依次为：首页、应用、相册、留言。第三屏直接轮播电视内已保存的照片，确定键才打开相册设置；方向键向上可逐屏返回。这里使用电视本机存储，原有家庭服务的开发相册仍保持关闭。

## 网页与原生模式

v39 起，WebView 低于 89 或版本未知时使用原生相册；网页加载失败也进入原生替代。原生模式支持本机照片浏览、全屏逐张播放、暂停与返回。v41已补上本机绘制的上传二维码，确认开启后即可扫码；网页轮播模板和照片管理仍限网页模式。原生二维码不依赖WebView。

进入上传前会显示原生确认框，默认选中取消。只有确认后的新按键操作才能开启；退出、切后台、页面更换或活动结束都会撤销，返回前台不会自动恢复。首页或相册启动不会自动开放上传端口。

## 手机上传

第三屏→“相册设置”→“扫码上传”。手机与电视连接同一家庭局域网，用手机浏览器扫码，选择照片上传。无需填写家庭服务地址或注册账号。上传窗口10分钟有效，离开设置即关闭；再次上传需重新开启并扫码。二维码含临时授权，请勿公开分享。

窗口只提供局域网HTTP上传，不开放相册读取或删除。使用受信任的家庭网络，勿把监听端口转发到互联网。电视会将照片转为最长边2560以内的显示副本并剥离EXIF定位信息，手机原图不变；另存480像素缩略图。4K屏展示效果取决于原图和模板，不是原始4K无损保存。

最多300张、主图共520MiB；单次上传不超过20MiB或4800万像素，保留至少128MiB可用空间。超出或格式不支持会提示失败，不覆盖已有照片。照片保存在开视应用内部，普通更新保留；卸载或清除应用数据会删除。

## 播放与管理

内置柔和叠化、慢慢推近、双幅画廊三个模板，8/12/20秒节奏。第三屏翻到即轮播；上下可翻屏，确定进入管理。另从管理进入全屏后左右切换、确定暂停或继续，返回/上下退出。每次进第三屏刷新本地照片；应用退到后台暂停轮播。

相册设置可设为屏保模式，保留时间、日期显示；没有照片时显示空状态。设置中选照片并确认删除，会同时删除主图与缩略图，无法撤销；手机原图不受影响。

本轮使用合成照片做浏览器和Android28模拟器验证；小米手机浏览器、家庭网络隔离及小米电视存储/屏保效果仍需实际测试。

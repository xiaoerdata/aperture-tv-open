## P06 · WorkBody 驱动的可定制化

> 对，我觉得传统的就是手机的，就是或者电视的这个管理系统，它的弱点就在于个性化可定制化不够，而且跟手机的这个联动是不够的。我们看看就是我们的这个电脑这个项目，就是能不能去做成开源的，然后让我们的 WorkBody这样的一个这个，就通过某种方式去认证连接，不管是局域网还是什么方式，连到我们的这个电视的这个系统上面，让 WorkBody可以去用一些可编程化可定制化的能力去赋予这个电视。我觉得这个是我们做这个项目的一个非常核心的差异化，也就是每天用户回到家里面，他跟自己的 WorkBody说一句话，连上网，这个 WorkBody就可以去给这个电视去做一些实时的这种调整跟反馈，这是一个很有意思的这种场景吧。我觉得你可以好好地去帮我去实现一下。

## P07 · 一次验证、后续交给 Agent

> 传统很多电视去更新一些内容，就需要去通过手机扫码，然后填入一些信息校复。我们就是把这个过程一定要完全交给 Agent Bot Body 去完成。当然你的验证也可以通过扫码，也没问题，但是扫码完之后就完成了握手和凭证的这个记录。我觉得再加上本地的这个网络的一个，你看看能不能做一个验证。我觉得这个其实就很好地已经可以实现这个认证的和账号封控的一个功能。

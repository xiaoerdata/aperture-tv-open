# 第一次使用开视 · 小米电视

**本项目仅适配小米电视。** Android8+是最低系统要求，不代表全部机型已验收。

本机应用与原生NAS可以先独立使用；共享日程、留言和连接助手时，再由电脑/NAS运行家庭服务。目标是让已有电视多一个家庭前台；当前为Alpha公开测试，尚无正式稳定版。先看[下载与版本](DOWNLOADS.md)，选择标准版或爸妈版；私有仓库协作者另有内测候选。

## 先选一条路线

| 你手上有什么 | 从哪里开始 |
| --- | --- |
| 只想先看界面 | 启动本机服务后打开 /guide，再进入示例家庭；不用输入真实家庭资料 |
| 较旧的小米电视，Android8+、系统WebView较旧 | 当前源码自动选原生简洁首页；家庭内容另走 /tv-lite，包版本见私有索引 |
| 小米电视Android8+、WebView89+ | 用 /tv 查看完整窗景，运行慢时切轻量模式 |
| 小米电视Android7及以前，或无法安装应用 | 不在本项目APK适配范围；保留原系统，不靠更换安装权限绕过系统版本要求 |
| 有NAS或家庭电脑、想连自己的助手 | 先配对电视，再按WORKBUDDY文档扫码授权助手 |

## 电脑上启动

需要Node.js22+、Python3.10+。以下命令适用于Linux/macOS/WSL，Windows可在WSL中运行；原生Windows安装脚本尚未验收。

```bash
npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
PATH="$PWD/.venv/bin:$PATH" npm run start:checked
```

启动检查会告诉你缺什么，不会输出管理口令。打开 `http://127.0.0.1:4318/guide`。运行目录的 `.data/owner-key` 是管理员口令，只在自己的手机/电脑登录时使用，不发给助手或录进视频。

## 先在一台电脑验证

1. 打开 /studio，展开“我是管理员”登录。
2. 用另一个浏览器窗口打开 /tv-lite，点“连接我的家”。
3. 管理员在“连接与窗景”输入电视的六位码并批准。这是电视首次只读授权。
4. 加一句留言，回电视窗口查看；轻量模式最多等待一个5秒轮询周期。
5. 在设备列表移除电视，确认下一次刷新后私人内容消失。

这个步骤验证家庭服务，不要求你先配置网盘或厂商账号。

## 家庭局域网快速试用

完成依赖安装后，停止上面的本机服务，执行：

```bash
npm run start:lan
```

从列表选择与电视、手机互通的家庭网卡。脚本检查依赖，只在选定地址监听；项目已有`.venv`时自动使用其中的Python。服务真正启动后，终端显示手机工作台二维码与“电视APK输入”地址。二维码只包含页面地址，手机仍需管理员登录；不会包含口令或自动批准设备。

手机扫码打开工作台，电视APK填写终端给出的完整源地址，再按前文完成电视的六位码配对。保持电脑和终端运行，Ctrl+C停止服务。不会修改系统网络、默认桌面或已有家庭数据。

如果不在交互终端，可明确指定本机真实地址：`npm run start:lan -- --address 192.168.1.50`。`--print-config`只查看地址，不启动、不创建数据。已有HOST/PUBLIC_ORIGIN时向导拒绝覆盖，请沿用`start:checked`。多网卡、VPN、Docker或WSL的地址不一定能被电视访问，需选择宿主机可达网络；这里不自动扫描电视。

这条路线仅用于受信任家庭网络HTTP内测，先使用合成资料。正式使用与跨设备助手连接请按DEPLOYMENT配置可信HTTPS；没有通过放宽助手的传输要求来简化配对。

## 搬到真正的电视

127.0.0.1指的是当前设备，电视不能用它访问电脑。按DEPLOYMENT配置局域网地址、监听和可信HTTPS，再用电视访问同一地址。电脑服务需要保持开启，路由器的访客网络隔离可能阻止互通。

现在提供Android外壳源码和已签名校验的私有debug候选；按ANDROID-PRIVATE-TEST在目标设备安装，或按ANDROID-LOCAL免费自行构建，保留原桌面和退出入口。若电视无法更新WebView，使用轻量页。完成型号、内核、安装、遥控器和网络记录后，才把它记为实测支持。

## 把日常更新交给自己的助手

按WORKBUDDY打开本机自动化。电脑配对脚本显示二维码，手机扫码确认范围与有效期，电脑自动保存独立凭证。随后让助手改标题、切完整窗景、加留言/日程/指标即可；到期、撤销或换IP后重新连接。首次电视配对与助手授权是不同的连接，不会自动把只读电视变成可写助手。

## 遇到问题

- 页面打不开：先确认电脑服务在线，再核对地址、端口、Host/PUBLIC_ORIGIN、路由器隔离和HTTPS证书。
- 电视空白：直接访问/tv-lite；检查是否允许JavaScript、是否为当前服务源。
- 图片失败：在同一运行环境执行npm run doctor，确认Python/Pillow；保留原文件，工作台会显示解码错误。
- 助手不能写：核对是否授权scene.write/content.write，令牌是否过期，来源IP是否变化；不要把管理口令填入MCP配置。
- 发生冲突或结果不明：助手先读原操作回执，再读当前内容，不换幂等键盲重试。

## 电视兼容性不确定时

先在电视浏览器打开家庭服务的 `/diagnostics`，选择建议的完整或轻量模式；试一下方向键和确认，再显示诊断摘要。它不需要管理口令，不读取家庭内容，也不会把摘要自动上传。把型号、系统关于页与检查结果放在真机记录里，再决定是否安装候选APK。

GitHub托管CI仍受到账户账单/额度阻塞，但已经验证[免费本地构建](ANDROID-LOCAL.md)并生成私有debug候选，不必为此恢复收费入口。按[私有APK验证](ANDROID-PRIVATE-TEST.md)下载、核对并安装。

## 给电视选择版本

[新版私有下载](DOWNLOADS.md)提供已校验的标准版与独立爸妈版，以索引的实际versionCode为准。标准版八入口；爸妈版突出看电视、看电视剧、看电影，下面一排较小的四个常用App快捷和所有应用。爸妈版「设置 → 常用应用」可添加、更换或移除；原桌面保留在设置。频道与片库由手机后台统一准备。两个包设置独立，可以同时安装。

本机客厅和常用App无需先启动家庭服务；家庭日程/照片、个人频道和片库仍需电脑或NAS在线。首次进片库未连接可直接按「连接这个家」，请家人批准只读码后留在原列表。原桌面可直接切回。v13默认不参选HOME，用户先在开视设置主动启用，再由系统选择；是否能替换Home和开机入口仍取决于小米固件。见[完整版本说明](LOBBY-AND-PARENTS.md)。


## 已有NAS，先不运行电脑服务

安装本版Android候选后，标准版从「影视 → NAS」、爸妈版从「设置 → NAS」进入，使用家里的只读共享账号。打开电影或电视剧目录，选择「将当前目录用于首页入口」；爸妈版以后从对应大入口直接打开，无需电脑网关或WebView89。标准版在我的家庭片库选择来源。已有v5只支持浏览，实际候选版本见私有下载索引。

家庭留言/日程/生活连接、服务器影院和频道仍按上面的家庭服务路线；原生NAS目录尚未合并海报、全局搜索或首页照片轮播。小米仅以最新Xiaomi智能存储为目标，五类NAS的实际型号/协议仍待测试。详见[NAS步骤](NAS.md)。

不想在电视输入NAS账号密码：源码v8可从NAS连接列表选择「用手机 / 助手配置NAS」。需要已配对的可信HTTPS家庭服务；扫码并验证管理员后，在手机填写，或由获nas.configure授权的本机Agent交接加密资料，电视测试后保存。HTTP局域网服务需先配置可信HTTPS，也可继续用本机手输。见[交接步骤](NAS-SETUP.md)，实际包以私有下载索引为准。

## 本机首页与家庭轻量屏分别选择

v10 的首页「设置 → 首页样式」可选玻璃或简洁首页，原生菜单名称为「玻璃 / 简洁本机首页」。WebView低于89自动使用原生简洁首页，现代内核也可手动选择；家庭屏仍单独按轻量/完整模式判断，不清除NAS、快捷或授权。渲染进程退出时回到原生首页，本次不自动重建网页。完整规则与真机待验项见[本机首页说明](HOME-MODES.md)。私有 v10 已包含这项选择；历史 v8 不包含。


## 在开视里安装与卸载应用

v13开始提供设置里的“安装应用”：选择本机APK，或从已连接NAS的全部文件里选择安装包。没有系统文件选择器的小米固件可使用NAS路线。先核对包名、版本和SHA-256，再由原系统授权来源和确认安装。具体步骤见[官方安装指引](../INSTALL.md)。

官方助手示例统一使用WorkBuddy。安装和卸载分别授予apps.install/apps.uninstall，默认不勾选，旧令牌不扩大；电视再开启一次十分钟的操作窗口，校验码核对后由WorkBuddy提交确定目标。系统确认仍在电视完成；发送、等待、完成和未知必须分开。未确认的操作不自动重试，更不能因为安装失败就自动卸载旧应用。客户端与小米真机由维护者测试，协议检查不是实机结果。

# 开视应用图标 · S53

按P50使用内置image_gen工具生成；P52明确要求简洁好记后重新设计，选用平面开放视窗：一条粗白边，右下斜切开口，没有播放三角、文字或立体玻璃材质。[选定原图](kaishi-icon-master-v2.png)与[最终提示词](PROMPT-v2.txt)保留，未调用外部API或配置新密钥。

[v1玻璃原图](kaishi-icon-master-v1.png)及[旧提示词](PROMPT-v1-rejected.txt)仅作被否定的过程记录，不再用于安装包。中途尝试的单字形状容易误读，没有选入。生图工具两次短暂连接失败后，重试内置工具成功，没有擅自改走收费API。

Android图标为等比缩小的512像素PNG，网页为192像素WebP；TV横幅640×360由缩小原图和Noto Sans CJK真实文字排版组成，爸妈横幅加版本名称。没有重绘生成图中的符号。实际生成尺寸、各文件摘要和选用标记见[清单](manifest.json)，不把提示词请求尺寸当作实际输出尺寸。

# S58 · 紧凑电视界面参考

按 P61 逐页使用内置 image_gen 生图。原图和完整提示词保留在本目录与 [prompts.json](prompts.json)。这些都是设计参考，不是实现截图或小米真机证据；不打包进 APK。未使用 CLI 或自带 API Key 的替代方式。

| 参考 | 对应实现 | 采用与取舍 |
|---|---|---|
| 01-home | launcher 首屏 | 小尺寸观看入口、折叠应用、单个可选摘要；保留大时间 |
| 02-parents | 爸妈首页 | 四个观看入口、较小常用应用；移除多个空占位 |
| 03-apps | launcher 第二屏及应用预设 | 应用图标与内容入口；用原厂预设/安装包图标，不采用模型生成的商标 |
| 04-family | launcher 家庭页、/tv、/tv-lite | 相册、安排、留言三部分；无相册时不保留大空卡 |
| 05-photos | launcher 相册 | 三列两行、较小页控；使用真实授权照片或明确空态 |
| 06-catalogue | 浏览器与原生影院目录 | 去掉巨大推荐区，标准版七列、爸妈版五列 |
| 07-detail | 影片详情、选集 | 小海报和右侧资料；原生详情内直接展示首线路前16集，保留完整选集 |
| 08-live | 直播频道 | 小台标和三列短行，按确认直进播放 |
| 09-nas | 原生 NAS | 单列文件行，照片小缩略图；不伪造媒体海报 |
| 10-settings | launcher 设置及更多设置 | 边栏式操作列表、44px以上焦点目标 |
| 11-pairing | 家庭配对、影院配对 | 缩小面板、连接码突出、返回焦点明确 |
| 12-nas-setup | 原生 NAS 配对及手机交接 | 有界表单，保留校验码、测试后保存和凭证边界 |
| 13-player | 影院/NAS 播放浮层 | 减少遮挡，播放中5秒收起、方向键唤回 |
| 14-workspace | 手机/电脑工作台各内容页 | 减少栏目和标题装饰；实际管理端保留清亮主题与共享移动控件 |
| 15-diagnostics | /diagnostics | 两栏检查与操作；实际值来自当前浏览器，保留非真机声明 |
| 16-guide | /guide | 小型预览、目录和操作步骤；使用实际开发截图，不用参考里的虚构家庭数据 |
| 17-native-home | 原生简洁首页 | 四个横向观看按钮、已配置应用和辅助按钮；不采用模型的彩色大卡 |
| 18-wallpaper | launcher 壁纸弹窗 | 缩略图选择、清晰焦点；保留原4K壁纸和出处，不把生图当实景素材 |
| 19-shelf | 原生观看记录、收藏、追剧 | 紧凑记录与有界操作菜单；不采用参考中虚构的进度/封面 |
| 20-media-source | 原生媒体来源 | 有界表单与列表，保留导入/插件确认边界 |
| 21-app-agent | WorkBuddy 安装/卸载窗口 | 有界状态面板、短说明和取消操作；实际系统确认保留 |
| 22-resource-agent | WorkBuddy 资源包导入窗口 | 单次范围、HTTP 选项和并排操作；不改变授权协议 |

参考图中出现的小米商标、额外影视海报、虚构账号、不同版本的开视标识均不采用；实际开视 Logo 沿用用户确认的第二套。多张生图没有严格遵守小尺寸要求，不能照图放大控件，实际尺寸以 [实现清单](../../docs/UI-COMPACT-S58.md) 为准。

共22张独立参考图。21 应用管理授权页曾连续两次连接失败；核对实际状态流程后修订提示词并成功生成。22 资源包授权页第一次连接失败，同一提示词重试成功。失败历史与成功提示词均已保留，不将模型生成的文本当作授权实现。

实际浏览器截图在 `docs/images/s58-*`；原生 Activity 仅完成源代码和 API 编译验证，没有本阶段原生运行截图。保留生成失败、布局修正及测试限制，详见过程日志 S58。

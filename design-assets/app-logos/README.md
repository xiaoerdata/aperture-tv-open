# 应用品牌图标 · S52

P49要求常用应用使用原厂Logo。12项预设现在使用官网下载文件、官方源码仓库文件或发布者提交到官方App Store的图片，保留原字节，不用文字重画商标。来源、时间、尺寸和摘要逐项保存在[manifest.json](manifest.json)。

这些图片用于服务品牌建议；如云视听小电视、云视听极光、银河奇异果、酷喵、咪视界的电视版图标可能不同。已安装时优先使用电视PackageManager读取的图标，随包服务品牌图不冒充实际安装状态。未知应用使用原创四格图形，名称仍单独显示。

不拉伸、不改色；图标本体与玻璃容器分开，应用名称放在图标之外。原生图标缓存提高到256×256，保留Drawable宽高比。应用展开、折叠、预设选择和爸妈快捷入口共用同一渲染函数；本机图标失败回退到随包原厂图，再失败使用通用图形。所有路径保持本地精确白名单，不请求外部图标服务。

## 复核

`node scripts/check-app-logos.mjs`核对原字节摘要、尺寸记录、12项目录对应和Android精确白名单。按manifest的HTTPS原始地址下载后必须先核对SHA-256；上游素材变化时不要静默替换，需要重新检查图形和品牌归属。

`node scripts/browser-app-logos-qa.mjs`在真实页面检查两版12项素材、图标优先级、双重失败和未知应用回退，保留S52截图。安装回调和PackageManager图片响应是夹具，不是电视实拍。官方素材可下载不等于开源授权，图片和商标不适用项目MIT，见[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 发现与取舍

部分官网首次请求返回412或空页面，使用官方专门下载页完成出处核对；没有绕过登录或获取私有素材。咪咕旧配置中的logo地址返回404，因此改用官方商店发布者图片。Netflix旧官网152像素白底字标没有选入，使用商店512像素N图标。失败候选未随项目分发；当前公开发行版仍是v17，本阶段只改本地源码。

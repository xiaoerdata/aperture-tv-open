NAS 直连

标准版从「影视 → NAS」、爸妈版从「设置 → NAS」进入，选择「添加连接」，使用 SMB 2/3 或 HTTPS WebDAV，填写共享目录与只读账号，测试后保存。小米最新独立智能存储仅按 SMB 路线待验。

打开电影或剧集目录，将当前目录指定给首页入口。电视直接读取 NAS；用手机或助手交接配置时，才需要先连接可信 HTTPS 家庭服务。

安装
与升级

安装确认与权限由原电视系统处理。

1

安装开视

下载标准版或爸妈版APK，核对版本与校验值；暂无发行包时可从源码构建。可在电视原系统文件管理中打开 U 盘里的 APK；具体支持情况以机型和系统提示为准。有开发经验的家人也可授权单台电视的 ADB 安装。无需 Root 或刷机。

安装后从原桌面的应用列表打开。默认不更换桌面；需要时在开视的默认桌面设置中主动开启，再由系统选择。

2

安装其他应用

开视设置 → 安装应用。选择本机APK，或从已连接NAS选择安装包；核对包名、版本与校验值后交给原系统安装器。没有系统文件选择器的固件可用NAS路线。完成后添加常用入口，原应用继续管理账号和数据。

爸妈版由家人在设置中准备，日常首页保留三个观看入口。也可授权WorkBuddy提交安装或非系统应用卸载，系统确认仍在电视上完成。

3

覆盖升级

下载同一个版本线、包名和签名一致的新版 APK，直接覆盖安装。不要先卸载；卸载会清除本地家庭连接与 NAS 配置。当前私有 debug 签名与未来正式版的升级安排将在正式发布前说明。

提示不兼容时，保留错误文字，核对 Android 版本、版本号与签名；不要关闭系统保护或卸载同名应用来尝试。

1

启动家庭服务

在电脑或 NAS 上运行开视服务。将手机、电视接入可互通的家庭网络，记下服务地址。

我是部署者，展开启动步骤

当前是源码开发版，需要 Node.js 22+、Python 3.10+ 和 Pillow。在项目目录执行：

npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
PATH="$PWD/.venv/bin:$PATH" npm run start:checked

家庭局域网内试用：完成依赖安装后执行 npm run start:lan，选择与电视互通的电脑网卡。服务启动后，终端给出电视地址和手机工作台二维码；二维码不含口令，手机仍需登录。先用合成资料做 HTTP 内测，正式使用与跨设备助手连接需可信 HTTPS。

本机打开 http://127.0.0.1:4318/studio。跨设备不能照抄 127.0.0.1，需要配置 HOST、PUBLIC_ORIGIN 和可信 HTTPS。详见源码 docs/DEPLOYMENT.md。

管理员口令存于私有的 .data/owner-key，不要录进视频。

2

配对电视

电视打开家庭服务的 /tv，点击「连接我的家」。手机工作台进入「连接与窗景」，输入电视上的六位码并批准。

代码五分钟有效，电视只获得展示权限。

小米电视怎么安装？

当前提供 Android 外壳源码和私有内测 debug 安装包，正式发行包待真机验证。目标 Android 8+；完整窗景要求 WebView 89+，旧内核可用轻量模式。安装步骤见源码 docs/ANDROID.md。

这是可退出的家庭前台应用。是否能设为默认桌面取决于固件，不自动刷机、Root 或禁用原桌面。

旧电视运行吃力，怎么选首页？

首页「设置 → 首页样式」可选择玻璃或简洁首页；原生菜单中名称为「玻璃 / 简洁本机首页」。低于 WebView 89 时自动使用原生简洁首页，现代内核也能手动选择。简洁首页不运行首页网页、背景图或轮播；已安装应用、NAS 和原桌面仍有入口。

它与家庭屏的轻量模式分别管理，不清除已有连接，也不改变系统默认桌面。网页显示组件退出时回到原生入口，本次不反复重开网页。需要重试时，在系统设置结束开视后重新打开，或重启电视。

Android 8+ 仍是安装目标下限；尚无旧电视性能或实际渲染进程退出验收。包是否含此功能，请核对私有下载索引与来源。

该选哪条路线？

电脑视频：把专门的文件夹设为媒体目录，只分享想让全家看到的内容。支持拖动进度，推荐 H.264/AAC MP4。

Jellyfin：限定一个家庭媒体库，令牌留在服务器。当前只做直放，不执行转码。

网盘、SMB、WebDAV：先由服务器或 Jellyfin 挂载，再走前两条路线。目前没有网盘账号直登或自动局域网发现。

直播：导入自己的 M3U，服务器只访问预先批准的来源。支持 HLS 播放链路；具体编码与电视内核仍需验证。不内置公共影视源。

电视能直接连 NAS 吗？

新版 Android 源码加入「家里的 NAS · 直连」，通过 SMB 2/3 或 HTTPS WebDAV 读取照片和影片，不需要电脑先挂载。小米仅以最新 Xiaomi 智能存储为目标，协议及品牌机型仍待实测；实际安装包版本请核对私有下载索引。网页影院继续使用上面的家庭服务路线。

家人首次填写共享目录与只读账号，资料加密保存在电视；不会继承小米电视账号。NAS连接列表可选择「用手机 / 助手配置NAS」：需先配对可信HTTPS家庭服务，手机管理员核对校验码后填写，或由获NAS配置权限的本机助手交接加密资料；电视测试目录后保存，手机区分等待与电视报告完成。原生本机手输与浏览仍不需要电脑中转。可将NAS目录指定为爸妈版电影/剧集入口；仍不自动合并海报和搜索，也不会自动上传家庭照片。

和 TVBox、影视仓是什么关系？

开视是家庭信息与媒体的入口，不执行 spider / JAR / JS 解析配置，也不提供付费内容解锁能力。

保留已有播放器，从 Android 外壳的「电视直播」或「影视仓」打开；账号和片源配置继续由原应用管理。

米家设备

  1. 在自己的 Home Assistant 安装小米官方 Xiaomi Home 集成，并在 Home Assistant 登录、选择家庭与设备。

常见问题

权限
与使用范围

个人信息会自动出现在电视上吗？

不会。预览默认不勾选，只有你选中的摘要会共享。连接凭证和未选原始字段不发给电视。共享内容对已连接的家庭成员可见。

断网、数据过期会怎样？

家庭屏保留已读取内容并提示中断；生活快照过期后显示「待更新」。直播、云端来源可能不可用；本地媒体也需要家庭网络和服务器在线。

现在是一套完整电视系统吗？

现在是可运行的自托管开发版。家庭屏、生活连接、可选影院与源码已提供；私有 debug APK 已生成并校验；公共仓库与 Alpha 测试下载已开放；小米电视真机复测、正式发行签名和云端部署待完成。

可以二次开发吗？

独立核心采用 MIT，场景、生活连接与媒体模块分别组织。第三方连接器保留各自许可。扩展请从源码里的 DEVELOPMENT、LIFE-CONNECTIONS 和 FAMILY-CINEMA 文档开始。

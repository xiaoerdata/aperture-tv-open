安装与使用

仅适配小米电视 · Android 8+ · Alpha 测试版

打开预览

  1. 下载安装包

    选择标准版或爸妈版，并核对版本与校验值。

    项目下载

  2. 安装到电视

    按机型支持的方式，从 U 盘或原系统文件管理打开 APK，完成系统确认。无需 Root 或刷机。

  3. 打开开视

    从原桌面的应用列表启动。默认保留原桌面；需要时由用户在系统中选择默认桌面。

直播与影视

标准版和爸妈版均有看电视、看电视剧、看电影、看综艺四个入口。家人先在设置中的「直播与影视来源」配置，日常直接观看。

电视本机

导入开视资源包、兼容 TVBox 配置、M3U 或直播文本清单。可进入频道、片库、选集，以及收藏、追剧和观看记录。

插件与解析器受运行时和授权范围限制，并非任意影视仓配置都可直接运行。不内置公共影视源。

家庭服务

在手机工作台的「家庭影院」开启片库，选择电脑目录或 Jellyfin，或导入 M3U。来源自动检测可检查可读性，电视是否支持编码仍需实播。

NAS 直连

  1. 在电视设置中打开 NAS，添加 SMB 2/3 或 HTTPS WebDAV 连接。Jellyfin 从媒体来源接入。
  2. 填写共享目录或服务地址与只读账号，测试后保存。凭证加密保存在电视。
  3. 选择影片、剧集或照片目录。可把目录指定给对应首页入口。

直接浏览无需电脑中转。手机或 WorkBuddy 交接配置时，需要先连接可信 HTTPS 家庭服务。小米 NAS 仅以最新智能存储为目标；小米、海康、绿联和群晖的具体机型仍需实测。

网盘与来源限制

网盘可经自己的 NAS 或 Jellyfin 挂载；没有自动继承网盘、小米账号的登录。请只共享希望在家庭设备上显示的目录。

家庭共享

家庭屏保留相册、当天安排和留言。未配置内容时显示简短空态；已有个人摘要仍可在标准版首页显示。

  1. 在电脑或 NAS 运行家庭服务，让手机、电视处于可互通的网络。
  2. 电视连接家庭服务，打开「连接家庭」，取得六位连接码。
  3. 手机登录工作台，在「设备」中批准连接。代码五分钟有效，电视获得只读展示权限。
  4. 在工作台添加照片、安排或留言。电视通过更新通知和轮询同步。
部署步骤

需要 Node.js 22+、Python 3.10+ 和 Pillow。在项目目录执行：

npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
PATH="$PWD/.venv/bin:$PATH" npm run start:checked

同机工作台：http://127.0.0.1:4318/studio。跨设备使用家庭网络地址和可信 HTTPS；127.0.0.1 只指向当前设备。

局域网开发试用可运行 npm run start:lan，按终端指引选择网卡。管理员口令在私有 .data/owner-key，不要分享或录屏。完整部署说明见源码 docs/DEPLOYMENT.md。

WorkBuddy

  1. 按照源码 docs/WORKBUDDY.md 开启本机自动化，在 WorkBuddy 电脑上发起配对。
  2. 手机扫码并登录家庭管理员，核对能力和有效期后批准。电脑领取并保存凭证。
  3. 授权后可更新家庭内容，交接 NAS 配置，或导入资源包。示例：“添加一条今晚七点吃饭的安排。”
  4. 在电视打开应用管理窗口后，WorkBuddy 可发起安装或非系统应用卸载，最终确认由原系统处理。

服务端写入与电视接收分别确认。手机设备列表可撤销本机助手，下一次调用即重新校验。WorkBuddy 客户端和小米电视真机体验仍需实测。

应用管理与升级

其他电视应用

设置 → 更多设置 → 安装应用。选择本机或 NAS 上的 APK，核对包名、版本和校验值，再交给原系统安装器。安装后添加到常用应用，原应用继续管理账号和数据。

开视升级

同包名、同签名版本可以覆盖安装。v17 的原签名已丢失，v18 起使用新的包名与持久发行签名；与旧版并存，需重新配对和配置 NAS。不要为升级先卸载旧版。

旧电视与原系统

设置 → 更多设置 → 首页样式，可选择玻璃首页或简洁本机首页。低于 WebView 89 使用简洁本机首页；家庭屏另有兼容模式，保留照片、安排和留言。

原桌面入口保留在设置中。默认桌面、小爱同学唤醒、小米账号与米家仍由原系统管理；开视不会自动接管账号或开启家电控制。

常见问题

家庭数据会被删除吗？

这次简化撤下了独立数据面板、生活连接编辑页和场景设置入口，没有删除已保存的数据或后台接口。家庭屏显示照片、安排和留言。

断网会怎样？

家庭屏保留已读取内容并提示连接中断。授权失效后会清除屏幕上的私人内容。直播和远程媒体依赖网络；NAS 直连依赖局域网。

已经完成小米电视验收了吗？

本项目处于 Alpha 阶段。浏览器、协议及代码检查不能代替具体小米机型的安装、遥控器、小爱、米家和媒体播放实测。

如何二次开发？

独立核心采用 MIT，第三方组件保留各自许可。参考源码 DEVELOPMENT、RESOURCE-PACK、WORKBUDDY 和 NAS 文档。家庭服务与电视本机媒体配置分别管理。
